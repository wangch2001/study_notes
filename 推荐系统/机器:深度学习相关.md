## c++中的智能指针

**智能指针（Smart Pointer）** 是 C++ 中管理动态内存的一种重要机制，它能在对象不再被使用时**自动释放内存**，从而避免内存泄漏和悬空指针等问题。

智能指针其实是一个 **类模板**，表现得像普通指针，但会自动管理内存释放。
 在析构函数中调用 `delete`，从而自动清理资源。

## python、java、C++的垃圾回收机制？

+ C++：**手动内存管理 + 智能指针辅助**
+ Java：**自动垃圾回收**
+ Python：**引用计数 + 垃圾回收器（循环检测）**

| 特性         | C++                              | Java                              | Python                        |
| ------------ | -------------------------------- | --------------------------------- | ----------------------------- |
| 内存管理     | 手动 (`new/delete`) + RAII       | JVM 自动GC                        | 引用计数 + 循环GC             |
| 主要机制     | 编译期生命周期控制               | 可达性分析 (Mark-Sweep/Compact等) | 引用计数 + 分代垃圾回收       |
| 回收时机     | 离开作用域                       | 不确定，由GC触发                  | 引用计数实时 + 周期性循环检测 |
| 是否有GC暂停 | ❌ 无                             | ✅ 有（STW）                       | ⚠️ 有时有（gc.collect）        |
| 控制粒度     | 最精确                           | 不可控                            | 部分可控（gc模块）            |
| 性能         | 最高，可预测                     | 稍慢，有GC开销                    | 较慢（解释器+GC）             |
| 内存安全性   | 易出错                           | 安全                              | 安全                          |
| 应用场景     | 高性能、实时系统（游戏、嵌入式） | 大型企业级系统                    | 快速开发、AI、数据分析        |

## 栈和堆

**栈（Stack）**

- 是由**编译器自动分配和释放**的内存区域；
- 用来存放**函数调用信息（栈帧）**、**局部变量**、**函数参数**等；
- 遵循 **后进先出（LIFO）** 原则。

**堆（Heap）**

- 是由**程序员或运行时系统动态分配**的内存；
- 生命周期**不受作用域限制**；
- 需要**手动释放**（或依赖垃圾回收）。

| 对比项       | 栈（Stack）                  | 堆（Heap）                   |
| ------------ | ---------------------------- | ---------------------------- |
| **分配方式** | 自动（系统分配）             | 手动（程序员或GC）           |
| **管理者**   | 编译器 / 操作系统            | 程序员 / 垃圾回收器          |
| **分配效率** | 高（顺序分配）               | 低（动态分配，需查找空闲块） |
| **内存大小** | 较小（通常几MB）             | 较大（受系统限制）           |
| **生命周期** | 随函数调用结束销毁           | 直到手动释放或GC回收         |
| **碎片化**   | 不会碎片化                   | 可能会碎片化                 |
| **访问速度** | 快（连续内存）               | 相对慢（分散分配）           |
| **典型用途** | 局部变量、函数参数、返回地址 | 动态对象、全局共享数据       |

## 怎么理解推荐系统中的embedding坍塌？

Embedding 维度坍塌是指特征 Embedding 虽然处在高维空间，但实际仅占据低维子空间，从而导致信息丢失。这种情况在大规模推荐系统中非常常见。  

这是因为后续特征交叉中的 MLP 与 Embedding 之间会产生耦合关系，简单来说就是 rank(AB) ≤ rank(A)，因此只要其中存在一个低秩特征，交叉后的结果也会是低秩的，这一现象同样在 FFM 特征交叉中出现。  

为了衡量 Embedding 是否发生坍塌，可以利用奇异值的分布来度量信息的丰富程度。但特征坍塌也不一定是坏事：在大多数情况下，严重的特征坍塌意味着表征维度被浪费，信息不足，从而损害模型效果。但在某些应用中，适度的坍塌可能是一种正则化效果（高维 Embedding 空间可能过拟合训练集），有助于减少过拟合。在实际推荐系统中，通常会通过减少显式特征交叉（如避免 DCNv2 这类结构），而更多依赖隐式交叉（如 DNN）来缓解坍塌问题。不过，这也可能导致 离线 AUC 下降 或 推荐效果降低 的副作用（显式特征交叉效果优于隐式）。

## 决策树

**基本原理：**

决策树通过 **一系列特征划分** 将样本空间不断分割成更纯的子集。

- 每次划分选择一个特征；
- 依据该特征的某个取值（或阈值）将数据集划分；
- 重复这一过程直到叶节点纯净或达到停止条件。

**“纯度” 的度量**

为了选择最优划分特征，需要定义“纯度（purity）”或“不纯度（impurity）”的度量标准。

 (1) 信息熵（Entropy）

用于 **ID3 / C4.5 算法**。

越纯净（即越倾向于某一类），熵越小。

 (2) 信息增益（Information Gain）

选择划分后，熵减少得越多，越好：

ID3 算法用这个指标选择特征。

(3) 信息增益率（Gain Ratio）

C4.5 用于修正 ID3 的“偏好多值特征”问题：

 (4) 基尼指数（Gini Index）

用于 **CART** 算法：越小代表越纯。

**停止条件**

树会一直分裂，直到：

- 节点样本全属于同一类；
- 或者样本数量小于阈值；
- 或者所有特征都用完。

**ID3**

**信息熵**

信息熵（Entropy）是接受信息量的平均值，用于确定信息的不确定程度，是随机变量的均值。

信息熵表示的是不确定度。均匀分布时，不确定度最大，此时熵就最大。

**信息增益**

当选择某个特征对数据集进行分类时，分类后的数据集信息熵会比分类前的小，其差值表示为信息增益。

**算法流程**

输入：数据集D，特征集A

输出：ID3决策树

- 对当前样本集合计算出所有属性信息的信息增益
- 先选择信息增益最大的属性作为测试属性，将测试属性相同的样本转化为同一个子样本
- 若子样本集的类别属性只含有单个属性，则分支为叶子节点，判断其属性值并标上相应的符号，然后返回调用处，否则对子样本递归调用本算法。

**ID3算法的优点：**

- 算法结构简单；
- 算法清晰易懂；
- 非常灵活方便；
- 不存在无解的危险；
- 可以利用全部训练例的统计性质进行决策，从而抵抗噪音。

**ID3算法简单，但是其缺点也不少：**

- ID3算法采用信息增益来选择最优划分特征，然而人们发现，信息增益倾向与取值较多的特征，对于这种具有明显倾向性的属性，往往容易导致结果误差；
- ID3算法没有考虑连续值，对与连续值的特征无法进行划分；
- ID3算法无法处理有缺失值的数据；
- ID3算法没有考虑过拟合的问题，而在决策树中，过拟合是很容易发生的；
- ID3算法采用贪心算法，每次划分都是考虑局部最优化，而局部最优化并不是全局最优化，当然这一缺点也是决策树的缺点，获得最优决策树本身就是一个NP难题，所以只能采用局部最优；

**C4.5**

**C4.5算法进行了以下几点改进：**

- 用**信息增益率**来选择属性，克服了ID3算法选择属性时偏向选择取值多的属性的不足
- 在决策树的构造过程中进行剪枝，不考虑某些具有很好元素的节点。
- 能够完成对连续属性的离散化处理。
- 能够对不完整数据进行处理。

**算法流程：**

1. 输入：训练数据集 D，包含若干样本和属性，每个样本有一个类标号
2. 输出：决策树
3. 终止条件：
   + 如果数据集中所有样本属于同一类别，则该结点为叶节点，类别为该类。
   + 如果属性集为空，或者样本在属性上取值相同，则将该结点设为叶节点，类别为数据集中样本数最多的类。
4. 选择最优划分属性
   + 计算信息熵、信息增益率
   + 先选出 **信息增益高于平均水平的属性**，再在其中选出 **信息增益率最大的属性** 作为划分属性
5. 处理连续属性：对连续型属性，C4.5 会 **寻找最佳切分点**（通常通过对属性值排序，测试相邻取值的中点作为候选切分点）。
6. 分裂数据集：按选定的属性（或切分点）将数据集划分到子节点，递归地为每个子节点继续建树。
7. **剪枝**：使用 **悲观剪枝法（pessimistic pruning）**，基于验证误差的估计，对生成的决策树进行自底向上的剪枝，防止过拟合。

**CART**

在数据挖掘中，决策树主要有两种类似：分类树和决策树。分类树的输出是样本的类别，回归树的输出是一个实数。分类和回归树，即CART（Classification And Regression Tree），也属于一类决策树。CART算法由决策树生成和决策树剪枝两部分组成：

- 决策树生成：基于训练数据集生成决策树，生成的决策树要尽量的大
- 决策树剪枝：用验证数据集对以生成的树进行剪枝并选择最优子树，这时用损失函数最小作为剪枝的标准。

CART算法既可以用于创建分类树，也可以用于创建回归树。CART算法的重要特点包含以下三个方面：

- 二分(Binary Split)：在每次判断过程中，都是对样本数据进行二分。CART算法是一种二分递归分割技术，把当前样本划分为两个子样本，使得生成的每个非叶子结点都有两个分支，因此CART算法生成的决策树是结构简洁的二叉树。由于CART算法构成的是一个二叉树，它在每一步的决策时只能是“是”或者“否”，即使一个feature有多个取值，也是把数据分为两部分
- 单变量分割(Split Based on One Variable)：每次最优划分都是针对单个变量。
- 剪枝策略：CART算法的关键点，也是整个Tree-Based算法的关键步骤。剪枝过程特别重要，所以在最优决策树生成过程中占有重要地位。有研究表明，剪枝过程的重要性要比树生成过程更为重要，对于不同的划分标准生成的最大树(Maximum Tree)，在剪枝之后都能够保留最重要的属性划分，差别不大。反而是剪枝方法对于最优树的生成更为关键。
- CART树生成就是递归的构建二叉决策树的过程，对回归使用平方误差最小化准则，对于分类树使用基尼指数(Gini index)准则，进行特征选择，生成二叉树。

**基尼指数**

基尼指数跟信息熵的概念是一样的都是描述混乱的程度。基尼指数Gini(D)表示的是集合D的不确定性，基尼指数Gini(D，A)表示数据集D经过特征A划分以后集合D的不确定性，基尼指数越大说明我们集合的不确定性就越大，所以思想基本上和信息熵的概念是一致的。

**我们在候选属性集合A中，选择哪个使得划分后基尼指数最小的属性作为最优划分属性.**

**算法的停止条件有：**

- 节点中的样本个数小于预定阈值，
- 样本集的Gini系数小于预定阈值（此时样本基本属于同一类），
- 或没有更多特征。

## 决策树的剪枝

决策树很容易发生过拟合，可以改善的方法有：

- 通过阈值控制终止条件，避免树形结构分支过细。
- 通过对已经形成的决策树进行剪枝来避免过拟合。
- 基于Bootstrap的思想建立随机森林。

**剪枝的分类**

为了避免决策树过拟合 (Overfitting) 样本，决策树要进行剪枝。CART剪枝算法为了能够对未知数据有更好的预测，从 “完全生长” 的决策树底部剪去一些子树，使决策树变小，模型变简单。预剪枝 (Pre-Pruning) 与后剪枝 (Post-Pruning) 是剪枝的两种情况。

**预剪枝**

预剪枝即是指在决策树的构造过程中，对每个节点在划分前需要根据不同的指标进行估计，如果已经满足对应指标了，则不再进行划分，否则继续划分。

树的增长不能是无限的，因此需要设定一些条件，若树的增长触发某个设定条件时，则树的增长需要进行停止继续。这些设定的条件称作停止条件 (Stopping Criteria), 常用的 停止条件如下：

1. 直接指定树的深度
2. 直接指定叶子节点个数
3. 直接指定叶子节点的样本数
4. 对应的信息增益量
5. 拿验证集中的数据进行验证，看分割前后，精度是否有提高。

由于预剪枝是在构建决策树的同时进行剪枝处理，所以其训练时间开销较少，同时可以有效的降低过拟合的风险。但是，预剪枝有一个问题，会给决策树带来欠拟合的风险，1，2，3，4指标，不用过多解释，对于5指标来说，

虽然，当前划分不能导致性能提高，但是，或许在此基础上的后续划分，却能使性能显著提高呢？

**后剪枝**

后剪枝则是先根据训练集生成一颗完整的决策树，然后根据相关方法进行剪枝。常用的一种方法是，自底向上，对非叶子节点进行考察，同样拿验证集中的数据，来根据精度进行考察。看该节点划分前和划分后，精度是否有提高，如果划分后精度没有提高，则剪掉此子树，将其替换为叶子节点。

相对于预剪枝来说，后剪枝的欠拟合风险很小，同时，泛化能力往往要优于预剪枝，但是，因为后剪枝先要生成整个决策树后，然后才自底向上依次考察每个非叶子节点，所以训练时间长。

**基于随机森林的决策分类**

随机森林是包含多个决策树的分类器。随机森林算法是由 Leo Breiman和Adele Cutler发展推论出的。随机森林，顾名思义就是用随机的方式建立一个森林，森林里面由很多的决策树组成，且这些决策树之间没有关联。

随机森林就是通过[集成学习](https://www.biaodianfu.com/boosting.html)的思想将多棵树集成的一种算法，它的基本单元是决策树，而它的本质属于机器学习的一个分支—集成学习(Ensemble Learning)方法。集成学习就是使用一系列学习器进行学习，并将各个学习方法通过某种特定的规则进行整合，以获得比单个学习器更好的学习效果的一种机器学习方法。集成学习通过建立几个模型，并将它们组合来解决单一预测问题。它的工作原理主要是生成多个分类器或模型，各自独立的学习和做出预测。

随机森林是由多棵决策树构成的。对于每棵树，它们使用的训练集是采用放回的方式从总的训练集中采样出来的。而在训练每棵树的节点时，使用特征是从所有特征中，采用按照一定比例随机的无回放的方式抽取的。

**随机森林的优点**

- 随机森林算法能解决分类与回归两种类型的问题，并在这两个方面都有相当好的估计表现；
- 随机森林对于高维数据集的处理能力令人兴奋，它可以处理成千上万的输入变量，并确定最重要的变量，因此被认为是一个不错的降维方法。此外，该模型能够输出变量的重要性程度，这是一个非常便利的功能。
- 在对缺失数据进行估计时，随机森林是一个十分有效的方法。就算存在大量的数据缺失，随机森林也能较好地保持精确性。
- 当存在分类不平衡的情况时，随机森林能够提供平衡数据集误差的有效方法。
- 模型的上述性能可以被扩展运用到未标记的数据集中，用于引导无监督聚类、数据透视和异常检测；
- 随机森林算法中包含了对输入数据的重复自抽样过程，即所谓的bootstrap抽样。这样一来，数据集中大约三分之一将没有用于模型的训练而是用于测试，这样的数据被称为out of bag samples，通过这些样本估计的误差被称为out of bag error。
- 研究表明，这种out of bag方法的与测试集规模同训练集一致的估计方法有着相同的精确程度，因此在随机森林中我们无需再对测试集进行另外的设置。
- 训练速度快，容易做成并行化方法

**随机森林的缺点**

- 随机森林在解决回归问题时并没有像它在分类中表现的那么好，这是因为它并不能给出一个连续型的输出。当进行回归时，随机森林不能够作出超越训练集数据范围的预测，这可能导致在对某些还有特定噪声的数据进行建模时出现过度拟合。
- 对于许多统计建模者来说，随机森林给人的感觉像是一个黑盒子——你几乎无法控制模型内部的运行，只能在不同的参数和随机种子之间进行尝试。

**随机森林的构造方法**

随机森林的建立基本由随机采样和完全分裂两部分组成。

1、随机采样

随机森林对输入的数据进行行、列的采样，但两个采样的方法有所不同。对于行采样，采用的方法是有回放的采样，即在采样得到的样本集合中，可能会有重复的样本。假设输入样本为N个，那么采样的样本也是N个，这样使得在训练时，每科树的输入样本都不是全部的样本，所以相对不容易出现over-fitting。对于列采样，采用的方式是按照一定的比例无放回的抽取，从M个feature中，选择m个样本（n<<M）。

2、完全分裂

在形成决策树的过程中，决策树的每个节点都要按完全分裂的方式来分裂，直到节点不能再分裂。采用这种方式建立出的决策树的某一叶子节点要么是无法继续分裂的，要么里面的所有样本都是指向同一个分类。

接下来，将介绍每科树的构造方法，步骤如下：

- 用N表示训练集的个数，M表示变量的数目
- 用m来表示当在一个节点上做决定时会用到的变量的数量
- 从N个训练案例中采用可重复取样的方式，取样N次，形成一组训练集，并使用这棵树来对剩余变量预测其类别，并对误差进行计算。

森林中任意两棵的相关性与森林中棵树的分类能力是影响随机森林分类效果（误差率）的两个重要因素。任意两棵树之间的相关性越大，错误率越大，每棵树的分类能力越强，整个森林的错误率越低。

## XGBoost建树的过程？为什么要用二阶导，可以用三阶导吗？

XGBoost（eXtreme Gradient Boosting）是一个 **基于梯度提升（Gradient Boosting）框架的树模型**。

> 它不是一次建一棵大树，而是**逐步叠加很多棵弱树（通常是CART回归树）**，让模型的预测不断逼近真实值。

| 步骤                                       | 说明                 |
| ------------------------------------------ | -------------------- |
| ① 计算每个样本的一阶导 (g_i)、二阶导 (h_i) | 衡量梯度方向与曲率   |
| ② 聚合到每个叶子节点 (G_j, H_j)            | 汇总统计量           |
| ③ 计算分裂收益 Gain                        | 依据目标函数改进程度 |
| ④ 选取 Gain 最大的分裂                     | 决定最佳特征与阈值   |
| ⑤ 递归建树 + 剪枝                          | 控制复杂度           |







**为什么用二阶导？**

✅ 直观解释：

- 一阶导（梯度）告诉我们：**方向** —— 误差往哪里减。
- 二阶导（Hessian）告诉我们：**曲率** —— 步子该多大、变化速率如何。

使用二阶导，能让步长更新更“自适应”，收敛更快、更稳定。

相比之下：

- 只用一阶导（如传统 GBDT）≈ 梯度下降；
- 用二阶导（XGBoost）≈ 牛顿法（Newton’s method），更新更精确。

**而如果再往上展开三阶项：**

得到非线性方程，没有解析解，需要迭代求解，计算复杂度暴涨。增益有限、几乎无收益，反而更噪声、稳定性低（高阶导震荡大）

## LightBoost 对 XGBoost的改进

**:one: 算法层面的改进：**

1. **基于叶子（leaf-wise）的生长策略**

   + XGBoost：按层（level-wise）生长树

     > 一次扩展同一层的所有节点；
     >
     > 每次分裂都保证树是“平衡”的；
     >
     > **优点**：结构规整，防止过拟合；
     >
     > **缺点**：会做很多“无用分裂”，计算量大。

   + LightGBM：按叶子（leaf-wise）生长树

     > 每次只选择**全局增益（Gain）最大的叶子节点**来分裂；
     >
     > 优先扩展最有价值的分支；
     >
     > **优点**：精度更高、收敛更快；
     >
     > **缺点**：树可能很深，容易过拟合（通常用参数 `max_depth` 控制）。

2. **基于直方图（Histogram）的特征分裂**

   + XGBoost 默认是“预排序算法”（Exact Greedy Algorithm）：

     > 每个特征的所有取值都排序；
     >
     > 对每个候选分裂点计算增益；
     >
     > 精确但计算量大、内存占用高。

   + LightGBM 使用 **直方图算法（Histogram-based Algorithm）**：

     > 先把连续特征离散化为固定数量的桶（bins）；
     >
     > 用直方图统计每个桶的梯度与二阶导；
     >
     > 通过累积直方图快速计算增益；
     >
     > 计算复杂度从 O(nlogn) 降到 O(n)。
     >
     > 牺牲一点精度 → 换取极大计算速度和内存节省。

3. **基于梯度的单边采样（GOSS）**

   + 在样本数量特别大的时候，LightGBM 不用所有样本；

     > 取出梯度大的样本（信息量高）全部保留；
     >
     > 从梯度小的样本中随机采样一部分；
     >
     > 并对采样样本的权重进行校正。

   + 保留了“难学样本”的信息，丢弃“已学会样本”的冗余信息，训练速度可提升 10 倍以上，精度几乎不损失。

4. **特征互斥捆绑（EFB, Exclusive Feature Bundling）**

   + 针对高维稀疏特征（如 one-hot 编码），LightGBM 引入 **EFB**；
   + 如果两个特征几乎不会同时非零（互斥），就把它们合并成一个特征；
   + 相当于对特征做“压缩打包”，极大减少特征数量。
   + 减少维度，提高构建直方图的效率，节省内存。

**:two: 工程层面改进**

| 项目           | XGBoost            | LightGBM             |
| -------------- | ------------------ | -------------------- |
| **分裂算法**   | 精确分裂（预排序） | 直方图近似分裂       |
| **样本采样**   | 随机采样           | GOSS（基于梯度）     |
| **特征降维**   | 无                 | EFB（互斥打包）      |
| **树生长策略** | Level-wise         | Leaf-wise            |
| **并行方式**   | 特征级并行         | 直方图级并行，更高效 |
| **内存占用**   | 较高               | 明显更低             |
| **大数据支持** | 好                 | 更好（分布式 + GPU） |

**3️⃣ 其他改进点**

+ **更好的 GPU 支持**
   LightGBM 的直方图算法天然适合 GPU 并行，速度提升显著。
+ **支持类别特征（categorical feature）**
   LightGBM 可以直接输入类别型特征（不需独热编码），自动找到最优分裂。
+ **内存占用更小**
  + 采用 8-bit/16-bit 压缩；

## 分类与回归预测差异？（离散类别标签s连续数值，交叉熵s均方误差）

+ 分类预测输出 **离散类别标签**，常用 **交叉熵损失**。
+ 回归预测输出 **连续数值**，常用 **均方误差(MSE)**。

**均方误差损失（Mean Squared Error, MSE）**

$$L_{MSE}=\frac{1}{n}\sum_{i=1}^{n}(y_{i}-\hat{y}_{i})^{2}$$

**交叉熵损失（Cross-Entropy Loss）**

+ 二分类公式：$$L_{CE}=-\frac{1}{n}\sum_{i=1}^{n}[y_{i}\log(\hat{y}_{i})+(1-y_{i})\log(1-\hat{y}_{i})]$$
+ 多分类公式：$$L_{CE}=-\frac{1}{n}\sum_{i=1}^{n}\sum_{k=1}^{K}y_{ik}\log(\hat{y}_{ik})$$

## Precision与recall计算、F1-score计算 

**Precision（精确率）**

含义：在所有被模型预测为正的样本中，有多少是真的正样本, 衡量“**预测结果的准确性**”。

$$Precision=\frac{TP}{TP+FP}$$

**Recall（召回率）**

在所有真实为正的样本中，有多少被模型找出来了，衡量“**没漏掉多少正样本**”。

$$Recall=\frac{TP}{TP+FN}$$

**F1-score 的公式是 Precision 和 Recall 的调和平均数：**

**F1 兼顾了精确率和召回率，适合样本不均衡的场景。**

$$F1=\frac{2\cdot Precision\cdot Recall}{Precision+Recall}$$

## 介绍L1正则化和L2正则化，他们为什么有用？L1正则不可导，如何进行优化？

**L1 正则（Lasso）**

- **公式**：
- $$L_{total}=L_{loss}+\lambda\sum_i|w_i|$$
- **作用**：对权重取绝对值约束。
- **特点**：会产生稀疏解（部分参数变为 0），有利于特征选择。
- **缺点**：优化时不可导点在 0 附近，会带来一定计算复杂度。

**L2 正则（Ridge）**

- **公式**：
- $$L_{total}=L_{loss}+\lambda\sum_iw_i^2$$
- **作用**：对权重平方约束。
- **特点**：会让权重整体变小（趋近于 0 但不为 0），防止过拟合，优化更稳定。
- **缺点**：不会产生稀疏解，特征选择能力弱。

**对比总结（口述版）**

- L1 会让部分权重直接变 0，适合做特征选择；
- L2 会让权重整体缩小，更适合防止过拟合；

**什么是正则化？**

在训练模型时，我们的目标是最小化损失函数，让模型尽可能地拟合训练数据。但是，如果模型过于复杂（例如，参数过多），它可能会“记住”训练数据中的噪声和随机波动，而不是学习到底层的规律。这会导致模型在训练集上表现很好，但在未见过的测试集上表现很差，这种现象就是**过拟合（Overfitting）**。

**正则化（Regularization）** 是一种为了防止过拟合而向损失函数中添加“惩罚项”的技术。这个惩罚项会对模型的复杂度（通常是模型参数的大小）进行惩罚，从而引导模型在拟合数据的同时，保持自身的“简单性”。

新的损失函数 = 原始损失函数 + 惩罚项

L1和L2正则化就是两种最常见的惩罚项。它们都通过限制模型参数（权重 `w`）的大小来降低模型复杂度。

**L2 正则化 (Ridge Regression / 权重衰减)**

L2 正则化是在原始损失函数的基础上，加上所有权重值的**平方和**。

$$L_{L2}=\text{Original Loss}+\lambda\sum_{i=1}^nw_i^2$$

其中：

- wi 是模型的第 i 个权重参数。
- ∑wi2 是惩罚项，即所有权重平方和的L2范数。
- λ (lambda) 是正则化强度系数，是一个超参数。λ 越大，对权重的惩罚就越重，模型就越趋向于选择更小的权重。

**为什么 L2 正则化有用？**

1. **鼓励权重变小，但不为零：** 为了最小化整体损失，模型不仅要减小原始损失，还要减小 ∑wi2。这会驱使模型的权重值都变得非常小。
2. **使模型更平滑、更简单：** 一个模型的权重值普遍较小，意味着输入特征的一个微小变动对输出结果的影响也较小。这样的模型对数据中的噪声不那么敏感，函数图像更平滑，泛化能力更强。
3. **权重衰减 (Weight Decay)：** 在使用梯度下降进行优化时，L2惩罚项对梯度的贡献是 −2λwi。这意味着在每次更新权重时，都会先将权重 wi 乘以一个小于1的系数（使其“衰减”），然后再减去原始损失的梯度。这会不断地将权重拉向0。

**效果总结：L2正则化会使模型的权重参数趋向于接近0，但通常不会等于0。它会让权重分布得更均匀，形成一个由许多小权重构成的“平滑”模型。**

**L1 正则化 (Lasso Regression)**

L1 正则化是在原始损失函数的基础上，加上所有权重值的**绝对值之和**。

$$L_{L1}=\text{Original Ioss}+\lambda\sum_{i=1}^n|w_i|$$

其中：

- ∣wi∣ 是模型第 i 个权重的绝对值。
- ∑∣wi∣ 是惩罚项，即所有权重绝对值之和的L1范数。
- λ 同样是正则化强度系数。

**为什么 L1 正则化有用？**

1. **产生稀疏性 (Sparsity)：** 这是L1正则化最核心、最重要的特性。与L2不同，L1正则化倾向于将许多不重要的特征的权重直接**推向精确的0**。
2. **自动进行特征选择：** 当一个特征对应的权重变为0时，这个特征就相当于从模型中被移除了。因此，L1正则化可以看作是一种自动进行特征选择的方法。这对于处理高维数据（特征非常多）尤为有用，可以帮助我们识别哪些特征是真正重要的。
3. **模型更具可解释性：** 一个稀疏的模型（只有少数非零权重）更容易解释。我们可以清楚地看到是哪些特征在对模型的预测起作用。

**效果总结：L1正则化会产生一个“稀疏”模型，即模型的大部分权重参数都为0。它在惩罚大权重的同时，还能实现自动特征选择。**

**L1 和 L2 的直观对比**

一个经典的几何解释是：

- L2正则化的约束条件 ∑wi2≤C 在二维空间中是一个**圆形**。损失函数的等高线与这个圆形相切时，切点很难恰好落在坐标轴上，所以权重 w1,w2 通常都不为0。
- L1正则化的约束条件 ∑∣wi∣≤C 在二维空间中是一个**菱形**。损失函数的等高线与这个菱形相交时，交点有很大概率出现在菱形的**顶点**上。而这些顶点正是在坐标轴上，这意味着其中一个权重为0。

**L1 正则项不可导，如何进行优化？**

L1惩罚项 λ∣w∣ 在 w=0 这一点是不可导的（有一个尖点），所以标准的梯度下降法不能直接应用。

提出了几种有效的优化算法：

1. **次梯度下降 (Subgradient Descent)**

这是对梯度下降的一种扩展。对于像绝对值函数这样的凸函数，即使在不可导点，我们也可以定义一个**次梯度（Subgradient）**集合。

- 对于 ∣w∣，当 w>0 时，梯度是 1。
- 对于 ∣w∣，当 w<0 时，梯度是 -1。
- 对于 ∣w∣，在 w=0 这个不可导点，它的次梯度是一个区间 `[-1, 1]` 内的任何值。

在次梯度下降算法中，当 w != 0 时，我们正常计算梯度。当 w=0 时，我们从次梯度区间 `[-1, 1]` 中选择一个值（通常选择0）作为梯度。

虽然理论上可行，但次梯度下降在 w=0 附近可能会来回震荡，收敛速度较慢。

2. **近端梯度下降 (Proximal Gradient Descent)**

这是目前解决这类问题更常用、更高效的方法，尤其是在信号处理和机器学习领域。其核心思想是把损失函数拆分为两部分：可导的光滑部分（原始损失）和不可导的凸函数部分（L1惩罚项）。

优化步骤分为两步：

1. **梯度下降步：** 先只对光滑部分（原始损失）进行一次标准的梯度下降更新。
2. **近端映射步 (Proximal Mapping)：** 对上一步更新后的结果，应用一个专门针对L1惩罚项的“修正”操作。这个操作被称为**软阈值算子 (Soft-Thresholding Operator)**。

软阈值函数的作用是：

- 将绝对值小于 λ 的权重直接**置为0**。
- 将绝对值大于 λ 的权重向0的方向**收缩**一个 λ 的距离。

$$\text{SoftThreshold}(w,\lambda)=\begin{cases}w-\lambda&\mathrm{if}w>\lambda\\w+\lambda&\mathrm{if}w<-\lambda\\0&\mathrm{if}|w|\leq\lambda\end{cases}$$

这个过程非常直观地实现了L1正则化的稀疏效果：它创建了一个“死区” `[-λ, λ]`，任何落入这个区间的权重都会被直接“杀死”变为0。

3. **坐标下降法 (Coordinate Descent)**

对于某些特定模型（如线性回归、逻辑回归），坐标下降法非常高效。它不是同时更新所有的权重 w，而是一次只选择一个权重 wi 进行优化，同时固定其他所有权重。这个过程对所有权重轮流进行，直到收敛。因为每次只优化一个变量，问题变得更简单，可以精确地找到使L1损失最小的解。

## SVM怎么解决高维线性不可分的问题？

SVM 支持向量机解决高维线性不可分问题的核心武器是 **核技巧 (Kernel Trick)**。将原始特征空间映射到一个更高维的空间，使得在高维空间中数据变得线性可分，从而可以用一个线性超平面进行分类。

**一、线性不可分问题的本质**

当样本在原始输入空间中无法用一条直线（或超平面）正确划分时，就称为**线性不可分**。例如在二维空间中，像“同心圆”那样的数据显然不能用一条直线分开。

**二、SVM 的核心思路**

SVM 的目标是找到一个**最大间隔超平面（Maximum Margin Hyperplane）**来分隔样本。
 当样本线性可分时，这个问题很简单。
 但当样本\**线性不可分**时，SVM 采用两步策略：

:one: **允许部分样本分类错误（软间隔 SVM）**

+ 引入**松弛变量** ξᵢ ≥ 0，允许一部分点被错分；
+ 同时在目标函数中加入惩罚项 C ∑ ξᵢ，控制间隔大小与分类错误之间的权衡；
+ 目标函数：$\min_{\mathbf{w},b,\xi}\frac12\|\mathbf{w}\|^2+C\sum_i\xi_i$
+ 约束条件：$y_i(\mathbf{w}^T\mathbf{x}_i+b)\geq1-\xi_i,\quad\xi_i\geq0$
+ 这就能在原空间中尽量拟合即使有少量噪声或不可分的情况。

:two: **使用核函数将数据映射到高维空间（核技巧）**

如果数据本身无法通过软间隔分开，SVM 通过核函数把它映射到更高维空间，在高维空间中数据可能是线性可分的。

+ 映射过程：$\phi:\mathbf{x}\to\phi(\mathbf{x})$
+ 目标变为：$\min_{\mathbf{w},b}\frac12||\mathbf{w}||^2$
+ 约束：$y_i(\mathbf{w}^T\phi(\mathbf{x}_i)+b)\geq1$
+ 由于直接计算 φ(x) 可能代价很高，SVM 引入了**核技巧（Kernel Trick）**：$K(\mathbf{x}_i,\mathbf{x}_j)=\phi(\mathbf{x}_i)^T\phi(\mathbf{x}_j)$
+ 只需计算样本间的**核函数值**，无需显式地映射到高维空间。

**核函数本质：**

> 在原空间中简单计算 $K(\mathbf{x}_i,\mathbf{x}_j)$，
>  等价于在高维空间中计算 φ(x_i) 与 φ(x_j) 的点积。

👉 我们“假装”做了复杂的高维变换，但实际上只做了一次简单的核函数运算！

| 核函数类型      | 公式                                        | 适用场景                         |
| --------------- | ------------------------------------------- | -------------------------------- |
| 线性核          | $K(x_i, x_j) = x_i^T x_j$                   | 数据本身线性可分或近似线性可分   |
| 多项式核        | $K(x_i, x_j) = (x_i^T x_j + c)^d$           | 适合具有交互特征的中等复杂度问题 |
| RBF核（高斯核） | ( K(x_i, x_j) = e^{-\gamma                  |                                  |
| Sigmoid核       | $K(x_i, x_j) = \tanh(\alpha x_i^T x_j + c)$ | 类似神经网络激活函数             |

**直观解释**

+ 在原始空间中，数据点可能像“环形”或“弯曲”的结构；
+ 核映射将数据“展开”或“拉直”，在更高维空间中形成一个可被线性超平面分开的形态；
+ 超平面再“投影回原空间”时，对应的是一个非线性的决策边界。

## LSTM相比RNN的好处，解决了RNN存在的什么问题

**RNN 存在两个关键问题：**

**梯度消失（Vanishing Gradient）**

- 在反向传播过程中，梯度要一层层乘以权重矩阵；
- 若权重 < 1，梯度会指数级衰减；
- 导致模型只能学习短期依赖，**记不住长序列信息**。

**梯度爆炸（Exploding Gradient）**

- 若权重 > 1，梯度会指数级膨胀；
- 导致训练不稳定，参数更新异常。

结果就是：

> RNN 对长期依赖建模能力差，训练难以收敛。

**LSTM 的设计思想**

通过引入“**门控机制（gating mechanism）**”来**控制信息的记忆与遗忘**，从而解决 RNN 的梯度消失问题。

| 门类型                    | 作用               | 公式                                        | 功能解释         |
| ------------------------- | ------------------ | ------------------------------------------- | ---------------- |
| **遗忘门（Forget Gate）** | 决定丢掉哪些旧信息 | $( f_t = \sigma(W_f[h_{t-1}, x_t] + b_f) )$ | 控制“记忆的遗忘” |
| **输入门（Input Gate）**  | 决定加入哪些新信息 | $( i_t = \sigma(W_i[h_{t-1}, x_t] + b_i) )$ | 控制“记忆的更新” |
| **输出门（Output Gate）** | 决定输出多少状态   | $( o_t = \sigma(W_o[h_{t-1}, x_t] + b_o) )$ | 控制“暴露的记忆” |

**LSTM 如何解决 RNN 的问题**

✅ 1️⃣ 解决梯度消失

- LSTM 的细胞状态 C_t 通过遗忘门控制线性传递；
- 在反向传播时梯度可以**沿着 C_t 直接流动**（几乎不衰减）；
- 相当于为梯度开了一条“高速通道”，保留长期依赖信息。

✅ 2️⃣ 可控记忆机制

- 通过门结构，模型能学习“何时记忆、何时遗忘”；
- 有效过滤噪声信息，只保留关键历史特征；
- 从而在长序列任务中表现更好（如文本翻译、语音识别）。

## LLM中为什么常用Decoder Only结构?

1. 架构简洁、适用于语言建模任务

   Decoder-only 模型源于 Transformer 的 Decoder 模块，其核心特点是：

   - **自回归（auto-regressive）生成**：当前时刻的输出只依赖于之前的所有输入（通过 masked self-attention）。
   - **因果掩码（causal mask）** 保证了模型只能看到过去的信息，适合“从左到右”逐字生成任务。

   这正好契合了语言建模任务的目标：预测下一个单词。

2. 推理效率更高，适合大规模部署

   + 生成时只需向前传播一步一步生成，相比 Encoder-Decoder 不需要重复 encode 整个输入。
   + 可以使用KV-Cache，进一步加速推理

3. 预训练目标简单且通用性强

   + Decoder-only 模型通常使用的是 **标准自回归语言建模目标**：
   + 模型易于训练；
   + 预训练语料可覆盖各种任务（QA、对话、总结等）；
   + 一个模型就能泛化多个任务，统一了训练目标，无需人工设计多种任务-specific heads。

4. 架构简化带来更好的工程实现与扩展性

## Self-attention的时间复杂度？整个Transformer的时间复杂度？

**Self-Attention 的时间复杂度**

假设：

- 输入序列长度为 n
- 每个 token 的隐藏维度为 d

时间复杂度 $O(n^2 d)$

**Transformer Encoder 层的整体复杂度**

一个标准的 Transformer Encoder 层包括两部分：

1. **Multi-Head Self-Attention** → $O(n^2 d)$
2. **Feed-Forward Network (FFN)** → $O(n d^2)$

因此单层 Transformer 的总复杂度为：$O(n^2d+nd^2)$

## 大模型MoE负载均衡

**MoE（Mixture of Experts）** 是一种让模型在不同输入上**激活不同子网络（专家）**的结构，核心目的是：

> 在保持模型总参数量巨大的同时，让每次前向计算只激活其中一小部分，显著降低计算开销。

在标准 Transformer 的某些层（通常是 FFN 层）替换为 **MoE 层**：

$$y=\sum_{i=1}^NG(x)_i\cdot E_i(x)$$

其中：

- $E_i(x)$：第 i 个专家（Expert）子网络；
- $G(x)$：门控网络（Gating Network），决定哪些专家被激活；
- $N$：专家总数；
- 通常仅激活前 k 个专家（如 Top-1 或 Top-2）。

**MoE 的负载不均衡问题**

在实际训练中，**Gating 网络的输出分布常常不均衡**，某些专家会被频繁选中，而有的几乎从不被激活。

+ 🚨 **计算不平衡**：某些 GPU 负载过高（热点专家），形成瓶颈；
+ 🚨 **通信不平衡**：All-to-All 通信中部分设备数据量极大；
+ 🚨 **训练不稳定**：部分专家梯度几乎为零，无法学习；
+ 🚨 **收敛变慢 / 模型退化**：模型等效于少数专家在工作。

**MoE 的负载均衡机制**

核心思想是：让门控网络在选择专家时，不仅考虑输入匹配度，还要让专家的激活次数保持均衡。

**常见负载均衡方法**

| 方法                                    | 代表模型                   | 主要思想                                                     | 公式或思路                                        |
| --------------------------------------- | -------------------------- | ------------------------------------------------------------ | ------------------------------------------------- |
| **1️⃣ 辅助损失（Load Balancing Loss）**   | Google Switch Transformer  | 给 gating 网络加正则，使每个专家使用率接近均匀分布           | ( L_{balance} = N \cdot \sum_i p_i \cdot f_i )    |
| **2️⃣ 噪声门控（Noisy Top-k Gating）**    | GShard, Switch Transformer | 在门控输出前加噪声扰动，增加专家多样性                       | ( G(x) = \text{softmax}(xW_g + \text{Noise}) )    |
| **3️⃣ Capacity 限制**                     | GShard, Switch Transformer | 每个专家设定最大容量（每批最多接收 M 个样本），超出部分丢弃或重路由 | 控制通信和显存负载                                |
| **4️⃣ Hash 路由（Hash-based Routing）**   | FastMoE, Megatron-LM MoE   | 直接通过哈希函数分配专家，天然平衡但牺牲自适应性             | ( \text{expert} = hash(\text{token_id}) \bmod N ) |
| **5️⃣ Sinkhorn / Optimal Transport 路由** | BASE Layers, V-MoE         | 使用最优传输或 Sinkhorn-Knopp 平衡 token 分配                | 解耦路由概率分布与专家负载                        |
| **6️⃣ Expert Choice Routing**             | DeepSpeed-MoE              | 专家主动选择 token，使每个专家接收等量输入                   | 反向均衡路由机制                                  |
| **7️⃣ Dynamic Capacity / Token Dropping** | Mixtral, DeepSeekMoE       | 动态调整每个专家容量或随机丢弃低概率 token                   | 平衡性能与效率                                    |

**实际工程中如何做负载均衡**

1. **门控正则化**：
    增加 $L_{balance}$​ 项到总损失中：

   $$L_{total} = L_{task} + \alpha \cdot L_{balance}$$

   其中 α 控制权重。

2. **限制专家容量（capacity factor）**：
    每个专家最多接收：

   $$M = \text{capacity factor} \times \frac{B}{N}$$

   超过部分丢弃或重路由。

3. **混合策略**：
    在 GShard、Switch、Mixtral 等模型中，通常同时使用：

   - 噪声路由（noisy gating）
   - 辅助平衡损失
   - 容量限制



## 为什么attention计算要除以根号d？

**Q 和 K 的点积大小随维度 d 增大而增大**
 假设 Query q 和 Key k 的每个分量服从均值 0、方差 1 的分布：

 $ q\cdot k=\sum_{i=1}^dq_ik_i $ 

期望是 0，但方差是 d。也就是说，随着维度 d 增大，点积的数值会越来越大。

**softmax 对数值大小很敏感**

- 如果输入过大，softmax 会趋近于 one-hot（极端偏向某个位置），导致梯度消失；
- 如果输入过小，softmax 近似平均分布，注意力不明显。

因此需要**控制数值规模**，避免维度增大导致的不稳定。

点积的方差是 d，标准差是 $\sqrt{d}$。
 为了让结果在不同维度下保持 **方差一致（大约为 1）**，所以要除以标准差  $\sqrt{d}$ ，而不是除以 d。

换句话说，**是标准化的思想**，类似 batch norm、layer norm：把数值缩放到合适区间，方便训练。

除以 $\sqrt{d}$ 就是“方差归一化”，保持数值分布稳定。

## transformer中的attention机制有位置感知能力吗？为什么attention中不直接加入位置信息，而是要依赖位置编码？

自注意力机制没有位置感知能力

**为什么不直接在 Attention 计算中加入位置信息？**

理论上，可以设计一种新的 Attention 机制，把位置索引 `i` 和 `j` 作为变量直接引入到 Q-K 点积的计算中。

但这么做有几个潜在的问题：

+ **丧失通用性和简洁性**：原始的自注意力机制非常简洁，它就是一个通用的、可学习的加权求和模块。一旦引入绝对位置 `i` 和 `j`，这个模块就变得复杂，并且与特定的位置绑定，可能会损害其泛化能力。
+ **难以处理长序列和相对位置**：如果直接使用绝对位置索引，模型很难学到“相距 k 个位置的两个词”这种相对位置关系。模型可能会记住“位置5的词对位置8的词很重要”，但无法泛化到“位置15的词对位置18的词也很重要”。模型需要的是通用的、可泛化的相对位置概念。
+ **计算效率：**Transformer 成功的关键之一是其高度的**并行计算能力**。Q, K, V 都可以通过一次矩阵乘法并行计算出来，注意力分数也可以通过一次大的矩阵乘法 `Q @ K.T` 全部算出。如果引入复杂的位置函数 `f`，可能会破坏这种优雅的并行结构。

## Transformer中位置编码为什么要设置为正弦/余弦函数？

Transformer 的自注意力机制（Self-Attention）是**无序的**：

- 它看的是所有 token 之间的相对权重；
- 不像 RNN 有自然的顺序，或 CNN 有固定的局部邻域。

因此，必须 **人为注入位置信息**，否则模型无法区分“猫咬狗”和“狗咬猫”。

$$PE_{(pos,2i)}=\sin\left(\frac{pos}{10000^{2i/d_{model}}}\right)\\PE_{(pos,2i+1)}=\cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$

1. 周期性 & 多尺度表示

   + 每个维度对应一个不同频率的正弦/余弦波；
   + 不同频率组合后，可以唯一表示任意位置。 类似于傅里叶基函数：可以把序列位置分解为不同频率的正弦波。

2. 相对位置信息可线性表示

   正弦/余弦编码的一个关键好处是：
    **任意两个位置的相对偏移，可以通过线性变换表示。**

   举个例子：

    $\sin(a+b)=\sin a\cos b+\cos a\sin b$ 

    $\cos(a+b)=\cos a\cos b-\sin a\sin b$ 

   这意味着：如果模型知道位置 a 的编码，它可以通过简单的线性变换推算出位置 a+b 的编码。

   换句话说，**模型能天然捕捉相对位置关系**，而不仅仅是绝对位置。

3. 位置范围可扩展

   因为正弦/余弦是**连续函数**：

   - 理论上可以外推到比训练时更长的序列（比最大训练长度大）；
   - 这点比 **可学习的位置 embedding（learnable positional embedding）** 好（learnable embedding 在没见过的长序列上会失效）。

4. 数值稳定 & 易于实现

   + sin 和 cos 都是 [-1,1] 范围的值，不会随位置爆炸；
   + 不需要额外训练参数；
   + 实现简单，计算高效。

周期性&多尺度表示、相对位置信息可线性表示、位置范围可拓展、数值稳定易于实现

## RoPE位置编码

**正余弦位置编码的复数旋转版本**

**动机**

+ 编码方式要**兼顾绝对位置**与**相对位置**信息
+ 编码方式在 **推理缓存场景**下也要高效（即已生成 token 的 key/value 缓存不需要因为新 token 出现而重新大规模更新）
+ 在自注意力（Attention）机制中能够**自然地体现位置差距**、以便模型学习“距离越远，可能越弱”或“邻近越强”这种偏好。

**概念**

- 核心思想：将 token 的 embedding 向量视为若干对维度（2维一对，类似将 d 维拆成 d/2 个 2维子空间），然后**按 token 所在位置 pos，对每一对维度向量做二维旋转（rotation）**。
- 旋转角度 θ 与位置 pos 和该维度/子空间的频率参数／尺度相关。
- 关键在于：当 Query 和 Key 均应用了这种旋转编码后，它们在计算 $Q \cdot K^\top$ 时，就内隐地包含了**相对位置差**的信息。因为旋转角度随 pos 线性增长，两个 token 的旋转差即代表它们的位置差距。
- 与传统 “embedding + positional_encoding（加法）” 不同，RoPE 是一种 **乘（或旋转变换）** 的方式。

**公式（简化版）**

假设你有维度 d，将其拆分成 d/2 个 2-维对：对于每个对 i（即维度对为 (2i,2i+1)）：

定义频率参数：

$\omega_i = \frac{1}{10000^{2i/d}}$

对于位置  pos：角度

$\theta_{pos,i} = pos \cdot \omega_i$

令 embedding 向量在维度对  (2i,2i+1)  为 $ (x_{2i}, x_{2i+1}) $。那么旋转后表示为：

$$\begin{pmatrix} x'_{2i} \\ x'_{2i+1} \end{pmatrix} =  \begin{pmatrix} \cos \theta_{pos,i} & -\sin \theta_{pos,i} \\ \sin \theta_{pos,i} & \;\cos \theta_{pos,i} \end{pmatrix} \begin{pmatrix} x_{2i} \\ x_{2i+1} \end{pmatrix}$$

这种方式使得 embedding 向量“随位置旋转”而变化。然后，对于 Key 和 Query，都应用这个旋转（或一方应用旋转）。在注意力计算中：

$\langle Q_{pos1}, K_{pos2} \rangle$

因为两边都旋转了不同的角度，最终的 dot product 会隐含角度差 $\theta_{pos1,i} - \theta_{pos2,i} = (pos1 - pos2)\cdot \omega_i$，从而编码了相对位置差。这样，attention 机制就能自然“看见”pos1 和 pos2 之间的距离。这个部分在 Medium 文章里也有形象说明。

**RoPE 的优点与缺点**

**优点**

- ✅ **自然编码相对位置**。不只是绝对位置，还能反映距离。
- ✅ **推理友好、缓存友好**。适用于自动回归生成模型（LLM）场景。
- ✅ **实现简单、效率高**。仅是角度计算 + 向量旋转，开销小。
- ✅ 在很多现代大模型中已被采用（如 LLaMA、GPT‑3 变体模型中），证明其实用。

**缺点 / 限制**

- ❌ **频率设定固定**：如果 ωi 设定不当，或者 pos 超出训练时的最大位置时，可能出现“超出训练窗口”泛化差的问题。
- ❌ 有研究指出：RoPE 的“最小频率”或“低维度”部分或许承载了语义，而“高频率”可能才更多用于位置，因此在距离极长时其相对位置衰减模式可能并不是预期那样。
- ❌ 虽然推理友好，但在 **极长序列（比训练中更长）** 的泛化能力仍然是研究热点— 有些场景下，编码可能不能很好延伸。

**作用位置**

计算 **Query (Q)** 和 **Key (K)** 之后、做注意力分数计算之前。

RoPE 是对 Q、K 向量进行“旋转编码”的操作，Value 不参与旋转。

## 介绍一下Attention机制，如何计算Query和Key的相似度？

在 Transformer 的经典 “Scaled Dot-Product Attention”（缩放点积注意力）中，Query 和 Key 之间的相似度用的是 **点积**（dot product）加上一个缩放因子。完整公式如下：

$$\text{Attention}(Q,K,V)=\text{softmax}\Big(\frac{QK^\top}{\sqrt{d_k}}\Big)V$$

更细节地：

1. 计算得分矩阵 $S=QK^\top $。如果 Q 的形状是 $(n,d_k)$ ，K 是 $(m,d_k)$ ，那么 S 是 (n,m)，其中 $S_{i,j}=q_{i}^{\mathsf{T}}k_{j}$ 表示 第 i 个查询和 第 j 个键 的相似度（点积）。
2. 然后对每个查询 i 的得分向量做缩放：除以 $\sqrt{d_k}$（这是为了避免点积在高维空间里数值过大、梯度不稳定） —— 这就是所谓 “scaled” 那一部分。
3. 接着对每个查询 i 的得分向量做 softmax，得到注意力权重（每个 j 对于 i 的权重）：

这种结构有以下几个优点：

- 点积计算高效、向量化实现简单；
- 缩放 $\sqrt{d_k}$ 有助于缓解得分过大、softmax 梯度饱和的问题；
- Softmax 保证每个查询对应的权重和为 1，使得输出是一个加权组合。

这个机制也就是 Transformer 论文里所使用的标准 Attention 方式。

## FFN层有什么作用？

简单来说，如果说**自注意力层是负责“收集和融合信息”**（让每个词看到并融合句子中其他所有词的信息），那么 **FFN 层就是负责“消化和提炼信息”**（对融合后的信息进行一次复杂的非线性变换，以提取更深层次的特征）。

:one: **增加非线性 (Adding Non-linearity)**

这是 FFN 层最根本、最基础的作用。

- **背景**：自注意力机制的计算，尽管有 Softmax，但其核心是基于 Q、K、V 的一系列线性变换（矩阵乘法）和加权求和。如果 Transformer 块只由自注意力层堆叠而成，那么整个网络的表达能力将非常有限，因为多层线性变换的叠加本质上还是一个线性变换。
- **作用**：FFN 层包含一个非线性激活函数（通常是 ReLU 或其变体 GELU）。它的存在打破了模型的线性，使得 Transformer 能够学习和拟合远比线性关系复杂得多的函数和模式。**没有非线性，深度学习就没有“深度”可言。**

**:two: 对每个位置的表示进行独立转换(Transformation of Representations)**

FFN 层在 Transformer 块中的位置非常关键：它位于自注意力层之后。

- **输入**：FFN 层的输入是自注意力层输出的向量。这个向量已经是一个“富含上下文”的表示了（比如，句子 "The bank of the river" 中的 "bank" 经过注意力层后，已经融合了 "river" 的信息，知道了自己是“河岸”而不是“银行”）。
- **处理方式**：FFN 层**独立地**对序列中的每一个词向量进行相同的变换。也就是说，它将每个词向量分别通过一个由两个线性层和激活函数组成的小型神经网络。
  - 它的操作是**“Position-wise”**的，即对每个位置（position）的向量应用完全相同的权重（W1, b1, W2, b2），但各个位置之间的计算是完全独立的，互不干扰。
- **输出**：输出一个经过深度加工和提炼后的新向量，这个新向量将被送入下一个 Transformer 块。

**:three: 增加模型容量和复杂度 (Adding Model Capacity)**

FFN 层的结构通常是一个“扩张再压缩”的模式。

$$\mathrm{FFN}(x)=\mathrm{ReLU}(xW_1+b_1)W_2+b_2$$

通常，第一个线性层会将输入向量的维度 dmodel（例如 512）**扩张**到一个更大的中间维度 dff（例如 2048，通常是 dmodel 的 4 倍）。经过 ReLU 激活后，第二个线性层再将其**压缩**回原始维度 dmodel。

**这个“扩张-压缩”结构的作用是：**

1. **提供一个更大的“思考空间”**：在更高维度的空间里，模型可能更容易分离和学习复杂的特征组合。
2. **增加大量参数**：FFN 层是 Transformer 模型中参数量的重要来源。更多的参数意味着模型有更大的容量去学习和记忆数据中的复杂模式。

 :star: **角色分工的类比：一次会议**

我们可以把一个 Transformer 块的工作流程比作一次高效的会议：

1. **自注意力层 (Multi-Head Attention) - 讨论与交流阶段**:
   - 会议室里的每个人（每个词）都有自己的观点（原始词向量）。
   - 为了形成综合意见，每个人都会听取（Attention）其他所有人的发言，并根据发言与自己议题的“相关性”，决定重点吸收哪些人的信息。
   - 这个阶段结束后，每个人脑中的观点都融合了全场的信息，变得更加全面和有上下文。这是**信息在序列成员之间的横向流动**。
2. **FFN 层 (Feed-Forward Network) - 独立思考与决策阶段**:
   - 现在，每个人都带着刚刚吸收到的所有信息，回到自己的座位上**独立思考**。
   - 他们用自己的一套复杂的、非线性的思维模式（FFN 的两层神经网络）对这些信息进行加工、提炼、拔高，形成自己最终的、更深刻的见解。
   - 这个阶段是**每个人内部的纵向深度加工**，与其他人的思考过程是并行的、独立的。

## LSTM与 Transformer的区别

**LSTM 是一个精巧的“串行”处理器，像人一样逐字阅读；而 Transformer 是一个强大的“并行”处理器，像鸟瞰一样一次性审视全局。**

**LSTM**

**架构:** 是一种**循环神经网络 (Recurrent Neural Network, RNN)** 的高级变体。它的核心是“循环”，即通过一个内部的“记忆细胞”（Cell State）来按顺序处理序列。

**处理方式:** **串行处理 (Sequential)**。LSTM 必须逐个时间步（例如，逐个单词）处理数据。要计算第 `t` 个单词的输出，它必须先完成第 `t-1` 个单词的计算，并将隐藏状态传递过来。这种设计天然符合语言的时序性。

**工作机制:** 依靠**门控机制（输入门、遗忘门、输出门）**来决定哪些信息应该被存入记忆、哪些应该被遗忘、哪些应该被输出。这使得它比普通 RNN 更擅长捕捉长距离的依赖关系。

## 推荐模型中的Embedding层维度如何选择？

经验公式：

$$\dim=6\cdot|V|^{0.25}=6\cdot(|V|)^{1/4}$$

其中 $|V|$ 是某个类别特征 / ID 的基数（即候选类别总数或词表大小等）。

这个公式作为经验法则有以下优点 /合理性：

1. **增长温和**
    维度不会随着类别数线性攀升，从而避免维度过度膨胀。
2. **简单易用**
    给定类别数就能快速算一个维度，是初始化 / baseline 的便捷起点。
3. **有部分经验支持**
    在一些社区讨论与代码示例里，人们确实用类似公式作为初步猜测。**可调整系数**
    如果你觉得 6 太大 / 太小，可以把这个系数换成别的常数（比如 5、8 等），以适应你具体的模型 /数据规模。

然而，作为一个启发式公式，它有不少局限与风险。

**它的局限性 /潜在问题**

以下是这个公式在实际应用中可能遇到的问题或不适用的情况：

1. **忽略频次 /稀疏性**
    这个公式只看类别数，却没有考虑每个类别 / ID 的出现频率分布。如果类别中很多是极低频或几乎没用的，给予它们较高的维度容易过拟合。
2. **忽略样本规模 /训练数据量**
    类别数大但样本或交互数据太少，这时即使维度按这个公式算出来，也可能欠拟合 / 噪音太大。最优维度与训练样本数 /信号强度有关。
3. **忽略模型 /下游任务结构**
    不同模型结构（MLP、Transformer、因式分解机、图模型等）对 embedding 表示能力的需求不同。一个公式可能对某些模型有效，对另一些模型并不合适。
4. **尺度常数 6 是任意的 / 无理论支撑**
    “乘以 6”这个系数是经验调试得出，并没有坚实的理论基础。对于不同任务可能需要不同常数。
5. **可能偏低 /偏高**
    对于非常大类别数或非常复杂语义特征，可能这个公式给出的维度不够（表达能力受限）。反之，对中小类别数可能给出维度过高，浪费资源。
6. **忽略正则化 /剪枝 /自动调整机制**
    在现代推荐系统里，很多 embedding 定制 / 剪枝 /动态调整方法（比如 PEP 等）使得“统一公式”不再理想。

## 讲一下你所了解的transformer ？

为什么要用多头？ 怎么评判多头学习的有效性？矩阵相似度怎么计算？ 为什么要用LN？

**核心结构**：

- Encoder-Decoder 架构（如原始翻译任务）或纯 Encoder（BERT）、纯 Decoder（GPT）。
- **Self-Attention** 机制：计算输入序列中各位置之间的依赖关系，替代 RNN 的序列建模。
- **位置编码**：弥补模型缺乏位置信息的问题。
- **前馈网络（FFN）+ 残差连接 + LayerNorm**：稳定训练、提升表达能力。

**优势**：

- 并行计算高效。
- 长距离依赖建模能力强。
- 易扩展到大规模数据和参数。

**为什么要用多头?**

+ **多头注意力（Multi-Head Attention）**：通过多个注意力头在不同的子空间中学习表示。

+ **好处**：
  + 不同头可以捕捉不同的关系模式（如句法依赖、语义联系）。
  + 提高模型的表达能力与鲁棒性。
  + 避免单一注意力机制的“偏置”问题。

**怎么评判多头学习的有效性**

- **量化指标**：
  - 模型整体的下游任务性能提升（如分类准确率、BLEU、Perplexity）。
  - 各头的注意力分布熵或多样性（避免所有头学到相同模式）。
- **定性分析**：
  - 可视化注意力权重，观察不同头是否关注不同结构（如长距离依赖、局部词组）。
  - Ablation study（移除部分头，观察性能变化）。

**矩阵相似度怎么计算**

常见方法：

- **余弦相似度**：衡量角度是否一致，适合表示语义相似度。
- **欧氏距离 / 曼哈顿距离**：几何距离。
- **核函数（RBF kernel）**：非线性相似度。
- **矩阵相似度**：可以通过 `trace(AᵀB)` 或 Frobenius 内积计算，也可逐行/列计算向量相似度再聚合。

**为什么要用 LayerNorm (LN)？**

+ **作用**：
  + 缓解梯度消失/爆炸。
  + 让不同层的输出分布更加稳定（减少 covariate shift）。
  + 提升训练速度和收敛性。

+ **对比 BN**：
  + LN 在样本维度归一化（不依赖 batch size），适合 NLP 中变长序列输入。
  + BN 依赖 batch 统计特性，更适合 CV 任务。



## 激活函数

**激活函数及每层适合什么样的激活函数？(sigmoid/softmax做输出， ReLU及变体做隐藏等)**

+ **输出层**：分类常用 **sigmoid（二分类）** 和 **softmax（多分类）**；回归任务一般用 **线性**。
+ **隐藏层**：主流是 **ReLU 及其变体**，因为收敛快、计算简单。

**激活函数各自具体的形式和优缺点？（主要从计算速度、梯度问题简单讲一下）**

+ $$\text{Sigmoid: }\sigma(x)=\frac1{1+e^{-x}}$$
  + 优点：输出在 [0,1]，可解释为概率。
  + 缺点：容易饱和，梯度消失，计算相对慢。
+ $$\text{Tanh:}\tanh(x)=\frac{e^x-e^{-x}}{e^x+e^{-x}}$$
  + 优点：输出在 [−1,1]，均值为零，收敛比 sigmoid 快。
  + 缺点：仍有梯度消失问题。
+ $$\text{ReLU: }f(x)=\max(0,x)$$
  + 优点：计算快，梯度传播稳定。
  + 缺点：会出现“死亡 ReLU”，即神经元长期输出 0。

**ReLU的变体？（解决死亡ReLU问题，稍微讲2-3个就行）**

+ **Leaky ReLU**: 给负数部分一个很小的斜率，避免完全死亡。
+ **Parametric ReLU (PReLU)**: 负半轴斜率可学习。
+ **ELU/GELU**: 在负区间平滑过渡，表现更好，常用于大模型。

**目前大模型主要用什么激活函数？**

+ 早期 Transformer 用 **ReLU**。
+ 后来改为 **GELU**，因为平滑且在负值部分更有表达力。
+ 一些最新模型也尝试 **SwiGLU、SiLU** 等。

**MHA的表达与公式？(Q,K,:线性变换；splt;点积与缩放： softmax:权重和累加)**

1. 输入经过线性变换得到

   $$Q=XW^Q,\quad K=XW^K,\quad V=XW^V$$

2. 计算注意力权重：

   $$\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

3. 多头并行：

   $$\mathrm{MHA}(X)=\mathrm{Concat}(head_1,\ldots,head_h)W^O$$

**为什么要缩放？（避免结果过大导致softmax梯度消失）**

- 没有缩放时，点积随维度增大而变大，softmax 进入饱和区，梯度趋近于 0。
- 缩放后保持数值稳定，避免梯度消失。

## 低秩分解的数学原理？

1. **基本思想**

假设有一个大矩阵 $$M\in\mathbb{R}^{m\times n}$$，秩为 r（即最多有 r 个线性无关的行/列）。

- 如果 r≪min⁡(m,n)，那么矩阵 M 就是 **低秩的**。
- 低秩矩阵往往能用更少的参数表示，起到 **压缩** 和 **去噪** 的作用。

------

2. **低秩分解的数学形式**

**矩阵分解形式**

任何秩为 r 的矩阵 M，都可以写成两个低维矩阵的乘积：

$$M\approx UV^\top $$

其中：

- $$\begin{aligned}&U\in\mathbb{R}^{m\times k},\\&V\in\mathbb{R}^{n\times k}\\&k\leq r_{s}\end{aligned}$$

这样：

- 原矩阵参数量：O(mn)，
- 分解后参数量：O((m+n)k)，大大降低存储和计算复杂度。

------

**与 SVD 的关系**

奇异值分解（SVD）告诉我们：

$$M=U\Sigma V^\top $$

其中 Σ 是对角矩阵，包含奇异值。

如果我们只保留前 k 个最大的奇异值：

$$M_k=U_k\Sigma_kV_k^\top $$

那么 $M_k$ 就是 **在 Frobenius 范数意义下最优的秩-k 近似矩阵**。

------

3. **优化目标视角**

在推荐系统中，往往不是完整矩阵，而是**稀疏观测**：

比如用户-物品打分矩阵 $R\in\mathbb{R}^{m\times n}$，已知部分元素，未知部分需要预测。

常见做法是：

$$\min_{U,V}\sum_{(i,j)\in\Omega}\left(R_{ij}-U_i^\top V_j\right)^2+\lambda(||U||^2+||V||^2)$$

其中：

- Ω：观测到的样本集合，
- $U_i$：用户 i 的隐向量，
- $V_j$：物品 j 的隐向量。

这就是 **矩阵分解的低秩假设**，即我们假设用户-物品交互矩阵是近似低秩的。

------

4. **数学原理总结**

1. **低秩假设**：数据存在潜在的低维结构。
2. **分解方法**：通过 $M \approx UV^\top$ 或 SVD 截断实现降维。
3. **最优性**：SVD 截断给出 Frobenius 范数下最优的秩-k 近似。
4. **应用**：推荐系统（矩阵补全）、NLP（词向量）、图像压缩、表示学习。

✅ 直白理解：
 低秩分解就是把一个“大而稀疏/冗余的矩阵”用两个“小矩阵”相乘来近似，从而发现数据里的“潜在维度”（latent factors），既能压缩计算量，又能提取出核心结构。



## SVD和PCA的区别，优劣各自是什么？

SVD（奇异值分解）和 PCA（主成分分析）常常一起出现，它们关系紧密，但并不完全一样。下面我给你分层解释：

------

1. **数学定义层面**

- **SVD（Singular Value Decomposition）**

  - 对任意矩阵 $A \in \mathbb{R}^{m \times n}$，都可以分解为：

    $A = U \Sigma V^\top$

    其中：

    - U：列正交的 m×m 矩阵
    - Σ：对角矩阵，奇异值（非负实数），按照大小排序
    - V：列正交的 n×n 矩阵

- **PCA（Principal Component Analysis）**

  - 关注的是**数据的协方差矩阵的特征分解**。

  - 假设数据矩阵 $X \in \mathbb{R}^{n \times d}$（每行是一个样本，已中心化），其协方差矩阵为：

    $C = \frac{1}{n} X^\top X$

  - PCA 就是对 C 做特征值分解，取前 k 个最大特征值对应的特征向量，作为主成分方向。

------

2. **关系**

其实 **PCA 可以通过 SVD 实现**：

- 如果对中心化后的数据矩阵 X 做 SVD：

  $X = U \Sigma V^\top$

- 那么：

  - V 的前 k 列就是 **PCA 的主成分方向**
  - Σ 就是协方差矩阵的特征值

👉 换句话说，PCA = “在协方差矩阵上做特征分解”，而 SVD 是更通用的分解方法。

------

3. **区别**

| 方面                   | **SVD**                                            | **PCA**                                    |
| ---------------------- | -------------------------------------------------- | ------------------------------------------ |
| **输入对象**           | 任意矩阵（方阵/非方阵都可以）                      | 必须是协方差矩阵（对称正定）               |
| **目标**               | 找到矩阵的奇异值与正交基，适用于压缩、求解低秩近似 | 找到数据方差最大的方向，用于降维           |
| **应用场景**           | 矩阵近似、矩阵压缩、隐语义分析（LSA）、推荐系统    | 降维、可视化、去噪、特征提取               |
| **输出**               | 左奇异向量、右奇异向量、奇异值                     | 主成分方向（特征向量）、方差大小（特征值） |
| **是否依赖数据中心化** | 不要求                                             | 必须中心化，否则主成分不正确               |

------

4. **优劣比较**

- **SVD 的优势**
  - 更通用，适用于任意矩阵
  - 在数值稳定性上比直接做特征分解更好
  - 可以用于非方阵情况
- **PCA 的优势**
  - 专门针对数据降维，解释性强（“最大方差方向”）
  - 结果直观，可以直接解释每个主成分对方差的贡献
  - 在机器学习特征提取、压缩数据维度上更自然

------

5. **总结一句**

- **SVD 是数学工具**，能分解任何矩阵。
- **PCA 是统计方法**，目的是找数据最大方差方向，可以通过 SVD 实现。

👉 常见理解：**PCA ⊂ SVD 的应用**。



　　PCA算法的主要优点有：

　　　　1）仅仅需要以方差衡量信息量，不受数据集以外的因素影响。　

　　　　2）各主成分之间正交，可消除原始数据成分间的相互影响的因素。

　　　　3）计算方法简单，主要运算是特征值分解，易于实现。

　　　　PCA算法的主要缺点有：

　　　　1）主成分各个特征维度的含义具有一定的模糊性，不如原始样本特征的解释性强。

　　　　2）方差小的非主成分也可能含有对样本差异的重要信息，因降维丢弃可能对后续数据处理有影响。

## LoRA调参和全局调参的区别，为什么冻结一部份参数达到的效果好

1. **全局调参（Full Fine-tuning）**

- **做法**：在下游任务中，把预训练模型的全部参数都解冻，进行梯度更新。
- **优点**：
  - 表达能力最强，理论上能适配任何下游任务。
- **缺点**：
  - 参数量非常大，显存/存储/训练开销高。
  - 极易 **过拟合**，因为大模型的容量太大，下游小数据集会让模型「忘记」原来的知识（灾难性遗忘）。
  - 迁移到不同任务时，每个任务都要保存一份完整的模型副本（成本高）。

------

2. **LoRA 调参（Low-Rank Adaptation）**

- **做法**：把预训练模型的权重 **冻结**，只在某些关键层（如 Transformer 的 Attention/Feed-Forward 层）插入可训练的「低秩矩阵」，训练时只更新这些额外参数。
- **优点**：
  - **参数量极小**（只需训练插入的低秩参数），内存和显存开销大幅降低。
  - 原模型参数不动，避免灾难性遗忘，保留了大部分的通用能力。
  - 对下游小数据集更鲁棒，不容易过拟合。
  - 一个预训练模型可以配合多个不同的 LoRA 模块（插件化切换）。
- **缺点**：
  - 理论上表达能力比全参更新弱（但在实践中往往足够）。

------

3. **为什么「冻结部分参数」会更好？**

1. **防止灾难性遗忘**
   - 全局调参会让预训练得到的通用知识被快速覆盖，导致原有能力丢失。
   - LoRA/部分冻结只改变一小部分权重，能保持「预训练知识」和「新任务知识」的平衡。
2. **正则化效果（implicit regularization）**
   - 冻结大部分参数，意味着模型搜索空间被限制在一个小范围，不容易在小数据集上过拟合。
   - 类似于在高维参数空间里给模型「加了约束」，让它只能在低维子空间里调整。
3. **利用预训练的强表示能力**
   - 大模型预训练时已经学到了丰富的语言/知识表示。下游任务往往只需要微调某些「任务特定的映射关系」。
   - 因此，不需要全局大改，只要通过 LoRA 模块补充偏移量，就能达到类似甚至更好的效果。
4. **参数效率 & 可复用性**
   - 训练 LoRA 只需存储很小的额外参数，可以同时维护多个任务的 LoRA 模块，而无需为每个任务复制整模型。

------

4. **类比**

- **全局调参**：像是重写一本书，每次新任务都要把整本书改写一遍。
- **LoRA 调参**：像是在书的页边加批注，只改必要的地方，大部分内容保持不动。

------

✅ **结论**：
 冻结大部分参数（如 LoRA）不仅能节省计算资源，还能避免灾难性遗忘、降低过拟合风险，反而比全参调优更稳定、更泛化。



## LayNorm、BatchNorm、RMSNorm

**Batch Normalization（BatchNorm）**

对同一层在一个 batch 中的激活值做均值方差归一化。

对每个特征通道 x：$\hat{\boldsymbol{x}}=\frac{x-\mu_B}{\sqrt{\sigma_B^2+\epsilon}}\\y=\gamma\hat{\boldsymbol{x}}+\beta $

其中：

- $\mu_B, \sigma_B^2$：在一个 batch 内的均值与方差
- $\gamma, \beta$：可学习的缩放和平移参数

🧮 归一化维度

以卷积网络为例：

- 对于输入 shape = `(N, C, H, W)`：
  - **BatchNorm** 在 **N 和 H×W 维度上求均值和方差**（即对每个通道计算统计量）。

✅ 优点

- 加快模型收敛，允许更大学习率；
- 具有轻微的正则化效果；
- 提升模型泛化性能。

⚠️ 缺点

- 对 batch size 敏感（小 batch 时统计不稳定）；
- 在 RNN 中难以使用；
- 推理阶段需使用训练时的滑动均值。

**Layer Normalization（LayNorm / LayerNorm）**

主要为了解决 RNN 无法使用 BatchNorm 的问题。
 它在**单一样本的特征维度上进行归一化**，与 batch 无关。

对单个样本的隐藏状态 $x \in \mathbb{R}^H$：

$$\hat{x}=\frac{x-\mu}{\sqrt{\sigma^{2}+\epsilon}}\\y=\gamma\hat{x}+\beta $$

其中：

- $\mu = \frac{1}{H} \sum_i x_i$
- σ$\sigma^2 = \frac{1}{H} \sum_i (x_i - \mu)^2$
- 归一化是在**特征维度**上进行的。

🧮 归一化维度

- 对每个样本的所有特征（如隐藏层维度）计算均值和方差；
- 与 batch size 无关。

------

✅ 优点

- 可在 **RNN、Transformer 等结构**中稳定使用；
- 对 batch size 不敏感；
- 无需区分训练/推理阶段。

⚠️ 缺点

- 相较 BatchNorm，有时训练速度稍慢；
- 在 CNN 中效果不如 BatchNorm。

**RMS Normalization（RMSNorm）**

**只使用输入的均方根（RMS）而不是均值和方差**，即**不进行均值中心化**。

对输入 $x \in \mathbb{R}^H$：

$$\mathrm{RMS}(x)=\sqrt{\frac{1}{H}\sum_{i}x_{i}^{2}}\\\hat{x}=\frac{x}{\mathrm{RMS}(x)+\epsilon}\\y=\gamma\hat{x}$$

与 LayerNorm 相比，RMSNorm 去掉了“减均值”的步骤，也通常没有偏置 β。

🧮 归一化维度

- 同样在**单一样本的特征维度上归一化**；
- 但仅基于二范数（RMS）。

------

✅ 优点

- 计算更高效；
- 在 Transformer 等模型中性能与 LayerNorm 相近；
- 减少归一化带来的信息损失。

⚠️ 缺点

- 不适合需要去均值的任务；
- 理论上表达能力略低于 LayerNorm（但实践上差别很小）。

| 特性                  | BatchNorm          | LayerNorm          | RMSNorm                            |
| --------------------- | ------------------ | ------------------ | ---------------------------------- |
| 归一化维度            | Batch 内的样本维度 | 每个样本的特征维度 | 每个样本的特征维度                 |
| 是否依赖 Batch Size   | ✅ 是               | ❌ 否               | ❌ 否                               |
| 是否减均值            | ✅ 是               | ✅ 是               | ❌ 否                               |
| 是否适用于 RNN        | ❌ 否               | ✅ 是               | ✅ 是                               |
| 是否需要区分训练/推理 | ✅ 需要             | ❌ 不需要           | ❌ 不需要                           |
| 是否有 γ、β 参数      | ✅ 有               | ✅ 有               | 仅 γ                               |
| 计算代价              | 中等               | 略高               | 较低                               |
| 典型应用              | CNN                | Transformer / RNN  | Transformer（尤其是 LLaMA 等模型） |



## Lazy decoder-only

基于 Transformer Decoder 的自回归架构 + 惰性计算（缓存/按需计算）。

+ “Decoder-only”：只用自回归部分建模序列。
+ “Lazy”：推理时只算新 token/新行为，避免重复算历史，节省大规模推荐系统的计算开销。

在业界（比如阿里、字节、Meta 推荐论文里），“lazy decoder-only” 经常指：

- 用 **Decoder-only Transformer** 来建模用户行为序列。
- **Lazy** 指：
  1. 训练时可以并行，但推理时只计算需要的部分，复用历史结果（比如 KV cache）。
  2. 不像 Encoder 那样全量交互，而是自回归式地预测下一个交互，更贴近推荐场景的 **顺序性**。

## KV cache机制

Transformer 推理时，尤其是自回归模型（如 GPT），每生成一个 token 都要重新计算整个注意力。

原始计算复杂度为：$$O(T^2)$$

其中 T 是上下文长度。

**KV Cache 原理**

在解码阶段：

- 对每个生成的 token，会计算：

  $$K_t = X_t W_K, \quad V_t = X_t W_V$$

- 注意力计算公式：

  $$\text{Attention}(Q_t, K_{1:t}, V_{1:t})$$

👉 这些 K, V向量在生成后不会改变，因此可以 **缓存起来**。

 **好处**

- 避免重复计算前面 token 的 K,V；
- 将时间复杂度从 $O(T^2)$降为 O(T)；
- 对长上下文推理效率提升极大。

**KV Cache 占用内存**

KV cache 是内存消耗的主要来源：

$$\text{Cache Size}\approx2\times T\times n_{layer}\times d_{model}$$

+ 2：K 和 V 各占一份缓存
+ T：当前上下文序列长度（context length）
+ n_layer：Transformer 的层数（blocks 数）
+ d_model：每个 token 的隐藏维度（embedding 维度）



## loss损失函数

**1）点式损失（Point-wise Loss）**

直接把推荐问题当成分类/回归问题，对每个 **用户-物品对** 预测一个分数。

- **交叉熵损失（Binary Cross-Entropy, BCE）**
  最常见的点击率（CTR）预测损失函数：

  $$ L=-\begin{bmatrix}y\log(\hat{y})+(1-y)\log(1-\hat{y})\end{bmatrix} $$

  - y：真实点击 (0/1)
  - y^：预测概率
    👉 用于二分类（点击、不点击）。

  **数学上的含义：**衡量两个概率分布 P与 Q 的差异。最小化它相当于让模型预测分布逼近真实分布。
  
  **工程上：**惩罚错误预测的概率，鼓励模型输出更高置信度的正确类别概率
  
  **推荐系统中：**衡量预测的点击/购买概率与用户实际行为的差异，是CTR/CVR模型最常用损失。
  
- **均方误差（MSE）**

  $$ L=(y-\hat{y})^2 $$

  👉 常用于评分预测（比如 Netflix 推荐的评分 1-5 星）。

- **交叉熵 + 样本权重**
  在推荐场景下正负样本极度不平衡，通常会对正样本/负样本加权，避免模型全预测 0。

**2）对式损失（Pair-wise Loss）**

关心的是 **两个物品之间的相对排序**。

- **BPR（Bayesian Personalized Ranking）**
  推荐领域最经典的 pair-wise loss，用于学习用户偏好排序：

  $$ L=-\sum_{(u,i,j)}\log\sigma(\hat{y}_{ui}-\hat{y}_{uj}) $$

  - 用户 u 对物品 i 有正反馈，对物品 j 没有反馈
  - 目标：让 i 的分数大于 j

- **Hinge Loss（最大间隔损失）**

  $$ L=\max(0,1-(\hat{y}_{ui}-\hat{y}_{uj})) $$

  👉 强调正样本必须比负样本至少大 margin。

- **RankNet Loss**
  基于 pair-wise 的概率建模，早期在搜索/推荐排序里常用。

**3）列表式损失（List-wise Loss）**

直接对一个候选列表进行优化，更接近业务目标。

- **Softmax Loss / ListNet**
  对一组物品预测的相关性做 softmax，再和真实分布对齐。
- **LambdaRank / LambdaMART**
  - 基于排序指标（比如 NDCG）直接优化，常用于学习排序（LTR）。
  - 思想：对 pair-wise 样本动态调整梯度，使得最终对 NDCG 等排序指标更友好。

**4）多任务损失（Multi-task Loss）**

- **加权求和**：

  $$ L=\alpha L_{CTR}+\beta L_{CVR}+\gamma L_{WatchTime} $$

  👉 在多任务模型（MMoE、PLE）里常见。

- **动态加权**：自动学习任务权重，比如 GradNorm、uncertainty weighting。

**🧩 一、回归问题常用的损失函数**

| 名称             | 英文名                         | 公式                                                  | 特点                                                         |
| ---------------- | ------------------------------ | ----------------------------------------------------- | ------------------------------------------------------------ |
| **均方误差损失** | Mean Squared Error (MSE)       | $ L = \frac{1}{n} \sum_i (y_i - \hat{y}_i)^2 $        | 对异常值敏感，平滑可微，最常见，对大误差的惩罚更重           |
| **均方根误差**   | Root Mean Squared Error (RMSE) | $ L = \sqrt{\frac{1}{n} \sum_i (y_i - \hat{y}_i)^2} $ | 与原值同量纲，直观解释误差                                   |
| **平均绝对误差** | Mean Absolute Error (MAE)      | $ L = \frac1n\sum_{i=1}^n$                            | 对所有误差一视同仁，对所有大小的误差都给予相同的线性权重，对离群点更具鲁棒性，更易于解释 |

**🧠 二、分类问题常用的损失函数**

| 名称                | 英文名                            | 公式                                                  | 特点                                                         |
| ------------------- | --------------------------------- | ----------------------------------------------------- | ------------------------------------------------------------ |
| **交叉熵损失**      | Cross-Entropy Loss                | $ L = -\sum_i y_i \log(\hat{y}_i) $                   | 最常用于分类问题（Softmax 输出）                             |
| **二元交叉熵损失**  | Binary Cross-Entropy              | $ L = -[y\log(\hat{y}) + (1-y)\log(1-\hat{y})] $      | 二分类标准损失                                               |
| **分类交叉熵损失 ** | Categorical Cross-Entropy Loss    | $L(y,\hat{p})=-\sum_{c=1}^{O}y_c\cdot\log(\hat{p}_c)$ | 通常与 `Softmax` 激活函数配合使用                            |
| **负对数似然损失**  | Negative Log Likelihood (NLLLoss) |                                                       |                                                              |
| **KL 散度损失**     | Kullback–Leibler Divergence       | $ L = \sum_i p_i \log(\frac{p_i}{q_i}) $              | 衡量两个概率分布的差异                                       |
| **Focal Loss**      | Focal Loss                        | $ L = -(1-\hat{y})^\gamma y\log(\hat{y}) $            | 标准交叉熵损失的一种改进，主要解决类别不平衡（如目标检测）问题 |

**🧩 三、排序与度量学习常用损失**

| 名称                    | 英文名              | 公式                                                      | 应用                                        |
| ----------------------- | ------------------- | --------------------------------------------------------- | ------------------------------------------- |
| **Hinge 损失**          | Hinge Loss          | $L = \max(0, 1 - y \cdot \hat{y}) $                       | 支持向量机（SVM），主要用于**最大间隔分类** |
| **Margin Ranking Loss** | Margin Ranking Loss | $L = \max(0, -y(\hat{y}_1 - \hat{y}_2) + \text{margin}) $ | 序列或排序任务                              |
| **Triplet Loss**        | Triplet Loss        | $L = \max(0, d(a,p) - d(a,n) + m) $                       | 人脸识别、度量学习                          |
| **Contrastive Loss**    | Contrastive Loss    | $ L = (1-y)d^2 + y\max(0,m-d)^2 $                         | 用于孪生网络（Siamese Networks）            |



## infoNCE Loss 和 Triplet Loss

这两个损失函数都常用于 **对比学习（Contrastive Learning）**，在推荐系统里主要用来学习 **用户/物品表示** 或者 **序列表示**，提高向量空间的区分能力。

**InfoNCE Loss（Info Noise Contrastive Estimation）**

InfoNCE 本质是 **带有 softmax 的对比学习损失**。
 给定一个 **正样本对** (q, k^+) 和一组 **负样本对** (q, k^-)，它的形式是：

$$ L=-\log\frac{\exp(s,k^+)/\tau)}{\exp(\sin(q,k^+)/\tau)+\sum_{k^-}\exp(\sin(q,k^-)/\tau)} $$

- q：查询向量（query）
- k^+：正样本（positive key）
- k^-：负样本（negative keys）
- sim(⋅)：相似度（常用点积/余弦）
- $\tau$：温度参数，控制分布平滑度

直观理解

- **目标**：让正样本的相似度比所有负样本都更高。
- **机制**：softmax 正则化，负样本越多，学习效果越强。
- **应用**：SimCLR、CLIP 里广泛使用，在推荐里常用于 **用户-物品对比学习** 或 **序列增强**（比如不同视角的行为序列 embedding）。

温度系数

τ 是 softmax 的“平滑因子”：

+ 缩放相似度→ 改变 logits 的相对差异。
+ 控制分布的平滑程度。

不同温度取值的影响：

+ 较小的 τ（比如 0.05, 0.1）
  + softmax 更尖锐（sharp），差距稍微大一点，相似度最高的样本概率会更接近 1。
  + 模型会 **强烈区分正负样本**，但训练可能不稳定（梯度过大）。
+ 较大的 τ（比如 0.5, 1.0 甚至更高）
  + softmax 更平滑，所有样本的概率差异变小。
  + 模型学习信号更弱，可能导致 **收敛慢或区分度不足**。

锚点

可以将用户序列表示 q作为锚点，与目标 item（正样本）/ 采样的其他 item（负样本）做对比。

工程实现时的小细节

- **归一化**：通常会 L2-normalize（单位化），避免相似度受向量长度影响。
- **投影层**：很多对比学习方法在 encoder 输出后还加一个 MLP 投影层（projection head），再取其作为 anchor，提升表达能力。
- **批内采样**：常见 trick 是直接用 mini-batch 里的其他样本当负样本，这样 anchor 计算只需一次前向传播，非常高效。

**Triplet Loss（三元组损失）**

Triplet loss 直接用 **margin 约束** 来比较正负样本的距离。
 一个三元组 = (anchor, positive, negative)，损失定义：

$$ L=\max(0,\:d(a,p)-d(a,n)+m) $$

- a：anchor（锚点，例如用户 embedding）
- p：正样本（positive，例如用户喜欢的物品）
- n：负样本（negative，例如用户没点的物品）
- d(⋅)：距离函数（欧氏距离/余弦距离）
- m：margin，要求正样本比负样本更接近至少 margin。

直观理解

- 强制：d(a,p)+m<d(a,n)。
- 如果正样本和负样本已经分开了（间隔 > margin），loss = 0。
- **应用**：早期人脸识别（FaceNet），在推荐里常用于 **embedding 学习**，确保用户和正物品比负物品更近。

## KL散度

KL 散度是用来**衡量两个概率分布之间差异**的一种方法。

在机器学习中，我们通常有一个“真实的”概率分布 P（代表客观世界的数据分布），以及一个我们训练的模型所学习到的“近似”概率分布 Q。KL 散度告诉我们，用分布 Q 来近似分布 P 时，会损失多少信息。

KL 散度可以被理解为：**当我们用一个近似分布 Q 来描述真实分布 P 时，所带来的信息损失（Information Loss）**。

- 如果两个分布完全相同（P = Q），那么信息损失为 0，KL 散度为 0。
- 两个分布差异越大，信息损失越多，KL 散度值也越大。

对于**离散**概率分布 P 和 Q，其 KL 散度的计算公式为：

$$D_{KL}(P||Q)=\sum_{x\in X}P(x)\log\left(\frac{P(x)}{Q(x)}\right)$$

对于**连续**概率分布 p 和 q，则将求和替换为积分：

$$D_{KL}(p||q)=\int_{-\infty}^\infty p(x)\log\left(\frac{p(x)}{q(x)}\right)dx$$

**公式解读：**

- P(x)（或 p(x)）：事件 x 在真实分布 P 中的概率。
- Q(x)（或 q(x)）：事件 x 在近似分布 Q 中的概率。
- P(x)/Q(x)：表示在事件 x 这一点上，两个分布概率的比值。
- log(…)：对这个比值取对数。如果 P(x) > Q(x)，则值为正；如果 P(x) < Q(x)，则值为负。
- ∑P(x)…：对所有可能的事件 x，计算这个对数比值的期望。权重是真实分布 P(x)，这意味着 KL 散度更关注**真实分布 P 中概率高的事件**所对应的差异。

**与交叉熵的关系**

在机器学习中，KL 散度与我们常用的**交叉熵损失（Cross-Entropy Loss）** 有着非常紧密的联系。

$$D_{KL}(P||Q)=H(P,Q)-H(P)$$

其中：

- DKL(P∣∣Q) 是 KL 散度。
- H(P,Q) 是 P 和 Q 的**交叉熵**。
- H(P) 是 P 的**熵**。

**交叉熵** H(P,Q) 表示用基于 Q 的编码方案去编码来自 P 的事件时，所需的平均比特数（即我们前面提到的“实际成本”）。 **熵** H(P) 表示最优编码方案（基于 P）去编码来自 P 的事件时，所需的平均比特数（即“理想成本”）。

在机器学习的分类任务中，我们的目标是让模型预测的分布 Q 尽可能地接近真实的标签分布 P。因为真实分布 P（训练数据）是固定的，所以它的熵 H(P) 是一个常数。

因此，**最小化 KL 散度 DKL(P∣∣Q) 就等价于最小化交叉熵 H(P,Q)**。

**关键特性**

+ 非负性 (Non-negativity)
+ 不对称性 (Asymmetry)

**总结**

- **核心思想**：KL 散度衡量用一个概率分布 Q 去近似另一个真实概率分布 P 时所造成的信息损失。
- **直观比喻**：它是用“次优”编码方案替代“最优”方案所付出的额外编码成本。
- **数值意义**：KL 散度为 0 表示两个分布完全相同；值越大，差异越大。
- **重要特性**：它是**非负**且**不对称**的，因此不是一个真正的距离度量。
- **与交叉熵的关系**：在机器学习中，最小化 KL 散度等价于最小化交叉熵损失函数。

## pre norm和post norm的区别

![image-20251029162538761](/Users/wangchanghao/Documents/study_notes/推荐系统/机器:深度学习相关.assets/image-20251029162538761.png)

`Pre-Norm` 和 `Post-Norm` 是 Transformer 模型中 **Layer Normalization（层归一化）** 两种不同的放置方式，它们对模型的训练稳定性、收敛速度和最终性能有显著影响。

✅ 1. Post-Norm（后置归一化）

公式：

$$ \text{Output} = \text{LayerNorm}(x + \text{SubLayer}(x)) $$

特点：

+ 优点
  + 残差连接在归一化之前，梯度可以直接流过 $x$，训练更稳定
  + 在浅层网络（如 12 层 BERT）中表现良好
+ 缺点
  + 在深层网络（如 > 50 层）中，**最后一层的 LayerNorm 会“掩盖”前面层的累积信号**，导致模型容量无法充分利用
  + 梯度在深层时容易衰减，训练困难

> 📌 适用于：**层数较少的模型**（如 BERT-base, 12 层）

✅ 2. Pre-Norm（前置归一化）

这是后来在深层模型中广泛采用的方式。

公式：

$$ \text{Output} = x + \text{SubLayer}(\text{LayerNorm}(x)) $$

特点：

+ 优点
  + LayerNorm 在子层之前，先对输入做归一化，**提升子层输入的稳定性**
  + 更适合**深层网络**，因为归一化提前，避免了深层梯度消失
  + 大模型（如 GPT、BERT-large）普遍使用
+ 缺点
  + 由于归一化在残差之前，**模型最后一层没有归一化**，输出的尺度可能不稳定
  + 训练初期可能不如 Post-Norm 稳定

> 📌 适用于：**深层模型**（如 GPT-3、BERT-large）

✅ 二、直观对比表

| 特性                   | Post-Norm               | Pre-Norm              |
| ---------------------- | ----------------------- | --------------------- |
| **LayerNorm 位置**     | 残差连接之后            | 残差连接之前          |
| **公式**               | $\text{LN}(x + F(x))$   | $x + F(\text{LN}(x))$ |
| **提出时间**           | 原始 Transformer (2017) | 后续改进（2018+）     |
| **训练稳定性**         | 浅层稳定，深层不稳定    | 深层更稳定            |
| **适合模型深度**       | 浅层（≤ 12 层）         | 深层（> 12 层）       |
| **梯度流动**           | 残差直接参与归一化      | 归一化提前，稳定输入  |
| **是否最后一层归一化** | ✅ 是                    | ❌ 否（最后一层无 LN） |
| **大模型主流选择**     | ❌ 否                    | ✅ 是                  |

------

✅ 三、为什么 Pre-Norm 更适合大模型？

在深层网络中：

+ Post-Norm 的 LayerNorm 在残差之后，会**重置每一层的输出分布**，导致深层网络的表达能力受限
+ Pre-Norm 提前归一化输入，让每一层的输入更稳定，**缓解梯度消失**，更容易训练

> 📌 实验表明：当模型超过 20 层后，**Pre-Norm 的收敛速度和最终性能通常优于 Post-Norm**。

------

✅ 四、有没有折中方案？—— DeepNorm, Post-LN with Scaling

随着模型变深，人们也在改进：

1. **DeepNorm**（2022）

+ 对残差连接加缩放：$ x + \alpha \cdot F(\text{LayerNorm}(x)) $
+ 配合 Pre-Norm，进一步稳定超深层训练

2. **Post-Norm with Warmup**

+ 使用 Post-Norm，但配合学习率预热和小初始化，也能训练深层模型

------

✅ 五、总结

| 选择建议                           | 推荐方案                        |
| ---------------------------------- | ------------------------------- |
| 训练一个 12 层以内的 BERT          | ✅ Post-Norm（原汁原味）         |
| 训练 GPT、大模型、深层 Transformer | ✅ **Pre-Norm**（工业界标准）    |
| 超深层模型（> 100 层）             | ✅ Pre-Norm + DeepNorm / Scaling |

> ✅ **一句话总结**：
>
> + **Post-Norm**：归一化在残差后，浅层稳定，适合小模型。
> + **Pre-Norm**：归一化在残差前，输入更稳，**大模型标配**。

在实际工程中，如果你在复现 GPT 或训练大模型，**默认使用 Pre-Norm**。

## 初始化方法

在深度神经网络中，如果初始化不合理，会出现两种常见问题：

| **问题**                           | **现象**                    | **原因**                       |
| ---------------------------------- | --------------------------- | ------------------------------ |
| **梯度消失（vanishing gradient）** | 深层网络不更新、loss 不下降 | 权重太小，前向信号逐层缩小     |
| **梯度爆炸（exploding gradient）** | loss 震荡或 nan             | 权重太大，梯度传播被放大       |
| **收敛慢、陷入坏局部最优**         | 优化困难                    | 不同层方差不匹配，激活分布失衡 |

所以初始化的目标是：

> **让每一层的输入和输出方差保持一致，使梯度既不消失也不爆炸。**

初始化方法按照发展顺序与思想，可以分为四大类：

| **类别**             | **方法**                  | **主要代表**                         |
| -------------------- | ------------------------- | ------------------------------------ |
| ① 随机初始化         | 均匀/高斯分布、常数初始化 | random uniform, normal, constant     |
| ② 方差控制型         | Xavier、He 初始化         | Xavier (Glorot), Kaiming (He)        |
| ③ 正交与特殊结构型   | 正交初始化、LSUV、LeCun   | Orthogonal, LSUV, LeCun              |
| ④ 预训练与数据驱动型 | 从预训练模型加载          | BERT, ViT, CLIP, ResNet 等权重初始化 |

**1️⃣ 常数与简单随机初始化**

最早期的做法。

**(a) 全零初始化**

W = 0

⚠️ 问题：所有神经元梯度相同 → 无法打破对称性 → 无法学习。

> ✅ 用于偏置项（bias）初始化，但不能用于权重。

**(b) 均匀 / 高斯分布随机初始化**

$$W \sim U(-a, a) \quad \text{或} \quad W \sim \mathcal{N}(0, \sigma^2)$$

问题：如果 a、σ 取值不当，会导致梯度消失或爆炸。

**2️⃣ Xavier 初始化（Glorot Initialization, 2010）**

> **目标**：保持前向传播和反向传播时，方差一致。

 **思想：**

对于一个全连接层：

y = W x

若输入方差为 Var[x]，则希望输出方差 Var[y] ≈ Var[x]。

 **适用场景：**

+ Sigmoid, Tanh 激活函数
+ 深度全连接网络

**3️⃣ He 初始化（Kaiming Initialization, 2015）**恺明初始化

> **目标**：针对 ReLU 类激活函数的非对称性优化方差。

因为 ReLU 会把一半输入置为 0（非对称），所以方差需要放大。

**适用场景：**

+ ReLU、LeakyReLU、ELU 激活函数
+ CNN / Transformer 前馈层常用

**4️⃣ LeCun 初始化（LeCun Normal）**

> 针对 Sigmoid / SELU 激活的优化。

**公式：**

$$W \sim \mathcal{N}\left(0, \frac{1}{n_{in}}\right)$$

**适用场景：**

+ SELU 激活函数（Self-Normalizing Networks）

**5️⃣ 正交初始化（Orthogonal Initialization）**

> **思想**：让权重矩阵保持正交，避免信息相关性，保持信号尺度。

 **公式：**

W^T W = I

在实践中：对一个随机矩阵做 QR 分解取 Q。

**适用场景：**

+ 深层 RNN（防止梯度消失/爆炸）
+ Transformer 中线性层

**6️⃣ LSUV 初始化（Layer-Sequential Unit Variance）**

> 一种动态初始化：

> 在前向传播时逐层调整缩放，使输出方差接近 1。

优点：自动化、稳定。

**7️⃣ 预训练初始化（Pretrained Initialization）**

> 直接使用大规模预训练模型参数作为初始化。

例如：

+ 用 ImageNet 预训练的 ResNet 权重初始化图像模型；
+ 用 BERT、CLIP 初始化 Transformer 模型。

优势：

+ 快速收敛；
+ 泛化性能好；
+ 适用于迁移学习。

**不同激活函数下的推荐初始化**

| **激活函数**            | **推荐初始化**      | **说明**         |
| ----------------------- | ------------------- | ---------------- |
| Sigmoid / Tanh          | Xavier              | 保持方差一致     |
| ReLU / LeakyReLU / GELU | He (Kaiming)        | 放大输入方差     |
| SELU                    | LeCun               | 保持自归一化性质 |
| Linear / Identity       | Xavier / Orthogonal | 信息保持性好     |

**总结对比表**

| **方法**                | **核心思想**     | **数学方差**   | **适用激活** | **优点**       | **缺点**       |
| ----------------------- | ---------------- | -------------- | ------------ | -------------- | -------------- |
| Random Uniform / Normal | 随机分布         | 自定义         | 通用         | 简单快速       | 容易梯度失衡   |
| Xavier                  | 输入输出方差一致 | 2/(n_in+n_out) | Sigmoid/Tanh | 收敛稳定       | 对 ReLU 不适用 |
| He (Kaiming)            | 考虑ReLU非对称性 | 2/n_in         | ReLU类       | 深层网络表现好 | 对非ReLU效果差 |
| LeCun                   | Self-Normalizing | 1/n_in         | SELU         | 稳定           | 仅限SELU       |
| Orthogonal              | 信息保持         | 固定           | 通用         | 防梯度爆炸     | 难于小网络     |
| LSUV                    | 动态调整方差     | 近1            | 通用         | 自动化好       | 预热慢         |
| Pretrained              | 数据驱动         | 无公式         | 通用         | 泛化强         | 需外部模型     |

参数初始化的核心目的是保持每层输入输出方差一致，避免梯度爆炸或消失。

常用方法有 Xavier（针对 Sigmoid/Tanh）、He 初始化（针对 ReLU）、LeCun（针对 SELU），

还有正交初始化和 LSUV 等改进方式。

不同激活函数和网络结构对应不同初始化策略，这是深层网络能稳定收敛的关键。
