# 面经

## pre norm和post norm的区别

![image-20251029162538761](./assets/image-20251029162538761.png)

`Pre-Norm` 和 `Post-Norm` 是 Transformer 模型中 **Layer Normalization（层归一化）** 两种不同的放置方式，它们对模型的训练稳定性、收敛速度和最终性能有显著影响。

✅ 1. Post-Norm（后置归一化）

公式：

$$ \text{Output} = \text{LayerNorm}(x + \text{SubLayer}(x)) $$

特点：

+ 优点
  + 残差连接在归一化之前，梯度可以直接流过 $x$，训练更稳定
  + 在浅层网络（如 12 层 BERT）中表现良好
+ 缺点
  + 在深层网络（如 > 50 层）中，**最后一层的 LayerNorm 会“掩盖”前面层的累积信号**，导致模型容量无法充分利用
  + 梯度在深层时容易衰减，训练困难

> 📌 适用于：**层数较少的模型**（如 BERT-base, 12 层）

✅ 2. Pre-Norm（前置归一化）

这是后来在深层模型中广泛采用的方式。

公式：

$$ \text{Output} = x + \text{SubLayer}(\text{LayerNorm}(x)) $$

特点：

+ 优点
  + LayerNorm 在子层之前，先对输入做归一化，**提升子层输入的稳定性**
  + 更适合**深层网络**，因为归一化提前，避免了深层梯度消失
  + 大模型（如 GPT、BERT-large）普遍使用
+ 缺点
  + 由于归一化在残差之前，**模型最后一层没有归一化**，输出的尺度可能不稳定
  + 训练初期可能不如 Post-Norm 稳定

> 📌 适用于：**深层模型**（如 GPT-3、BERT-large）

✅ 二、直观对比表

| 特性                   | Post-Norm               | Pre-Norm              |
| ---------------------- | ----------------------- | --------------------- |
| **LayerNorm 位置**     | 残差连接之后            | 残差连接之前          |
| **公式**               | $\text{LN}(x + F(x))$   | $x + F(\text{LN}(x))$ |
| **提出时间**           | 原始 Transformer (2017) | 后续改进（2018+）     |
| **训练稳定性**         | 浅层稳定，深层不稳定    | 深层更稳定            |
| **适合模型深度**       | 浅层（≤ 12 层）         | 深层（> 12 层）       |
| **梯度流动**           | 残差直接参与归一化      | 归一化提前，稳定输入  |
| **是否最后一层归一化** | ✅ 是                    | ❌ 否（最后一层无 LN） |
| **大模型主流选择**     | ❌ 否                    | ✅ 是                  |

------

✅ 三、为什么 Pre-Norm 更适合大模型？

在深层网络中：

+ Post-Norm 的 LayerNorm 在残差之后，会**重置每一层的输出分布**，导致深层网络的表达能力受限
+ Pre-Norm 提前归一化输入，让每一层的输入更稳定，**缓解梯度消失**，更容易训练

> 📌 实验表明：当模型超过 20 层后，**Pre-Norm 的收敛速度和最终性能通常优于 Post-Norm**。

------

✅ 四、有没有折中方案？—— DeepNorm, Post-LN with Scaling

随着模型变深，人们也在改进：

1. **DeepNorm**（2022）

+ 对残差连接加缩放：$ x + \alpha \cdot F(\text{LayerNorm}(x)) $
+ 配合 Pre-Norm，进一步稳定超深层训练

2. **Post-Norm with Warmup**

+ 使用 Post-Norm，但配合学习率预热和小初始化，也能训练深层模型

------

✅ 五、总结

| 选择建议                           | 推荐方案                        |
| ---------------------------------- | ------------------------------- |
| 训练一个 12 层以内的 BERT          | ✅ Post-Norm（原汁原味）         |
| 训练 GPT、大模型、深层 Transformer | ✅ **Pre-Norm**（工业界标准）    |
| 超深层模型（> 100 层）             | ✅ Pre-Norm + DeepNorm / Scaling |

> ✅ **一句话总结**：
>
> + **Post-Norm**：归一化在残差后，浅层稳定，适合小模型。
> + **Pre-Norm**：归一化在残差前，输入更稳，**大模型标配**。

在实际工程中，如果你在复现 GPT 或训练大模型，**默认使用 Pre-Norm**。

## 初始化方法

在深度神经网络中，如果初始化不合理，会出现两种常见问题：

| **问题**                           | **现象**                    | **原因**                       |
| ---------------------------------- | --------------------------- | ------------------------------ |
| **梯度消失（vanishing gradient）** | 深层网络不更新、loss 不下降 | 权重太小，前向信号逐层缩小     |
| **梯度爆炸（exploding gradient）** | loss 震荡或 nan             | 权重太大，梯度传播被放大       |
| **收敛慢、陷入坏局部最优**         | 优化困难                    | 不同层方差不匹配，激活分布失衡 |

所以初始化的目标是：

> **让每一层的输入和输出方差保持一致，使梯度既不消失也不爆炸。**

初始化方法按照发展顺序与思想，可以分为四大类：

| **类别**             | **方法**                  | **主要代表**                         |
| -------------------- | ------------------------- | ------------------------------------ |
| ① 随机初始化         | 均匀/高斯分布、常数初始化 | random uniform, normal, constant     |
| ② 方差控制型         | Xavier、He 初始化         | Xavier (Glorot), Kaiming (He)        |
| ③ 正交与特殊结构型   | 正交初始化、LSUV、LeCun   | Orthogonal, LSUV, LeCun              |
| ④ 预训练与数据驱动型 | 从预训练模型加载          | BERT, ViT, CLIP, ResNet 等权重初始化 |

**1️⃣ 常数与简单随机初始化**

最早期的做法。

**(a) 全零初始化**

W = 0

⚠️ 问题：所有神经元梯度相同 → 无法打破对称性 → 无法学习。

> ✅ 用于偏置项（bias）初始化，但不能用于权重。

**(b) 均匀 / 高斯分布随机初始化**

$$W \sim U(-a, a) \quad \text{或} \quad W \sim \mathcal{N}(0, \sigma^2)$$

问题：如果 a、σ 取值不当，会导致梯度消失或爆炸。

**2️⃣ Xavier 初始化（Glorot Initialization, 2010）**

> **目标**：保持前向传播和反向传播时，方差一致。

 **思想：**

对于一个全连接层：

y = W x

若输入方差为 Var[x]，则希望输出方差 Var[y] ≈ Var[x]。

 **适用场景：**

+ Sigmoid, Tanh 激活函数
+ 深度全连接网络

**3️⃣ He 初始化（Kaiming Initialization, 2015）**恺明初始化

> **目标**：针对 ReLU 类激活函数的非对称性优化方差。

因为 ReLU 会把一半输入置为 0（非对称），所以方差需要放大。

**适用场景：**

+ ReLU、LeakyReLU、ELU 激活函数
+ CNN / Transformer 前馈层常用

**4️⃣ LeCun 初始化（LeCun Normal）**

> 针对 Sigmoid / SELU 激活的优化。

**公式：**

$$W \sim \mathcal{N}\left(0, \frac{1}{n_{in}}\right)$$

**适用场景：**

+ SELU 激活函数（Self-Normalizing Networks）

**5️⃣ 正交初始化（Orthogonal Initialization）**

> **思想**：让权重矩阵保持正交，避免信息相关性，保持信号尺度。

 **公式：**

W^T W = I

在实践中：对一个随机矩阵做 QR 分解取 Q。

**适用场景：**

+ 深层 RNN（防止梯度消失/爆炸）
+ Transformer 中线性层

**6️⃣ LSUV 初始化（Layer-Sequential Unit Variance）**

> 一种动态初始化：

> 在前向传播时逐层调整缩放，使输出方差接近 1。

优点：自动化、稳定。

**7️⃣ 预训练初始化（Pretrained Initialization）**

> 直接使用大规模预训练模型参数作为初始化。

例如：

+ 用 ImageNet 预训练的 ResNet 权重初始化图像模型；
+ 用 BERT、CLIP 初始化 Transformer 模型。

优势：

+ 快速收敛；
+ 泛化性能好；
+ 适用于迁移学习。

**不同激活函数下的推荐初始化**

| **激活函数**            | **推荐初始化**      | **说明**         |
| ----------------------- | ------------------- | ---------------- |
| Sigmoid / Tanh          | Xavier              | 保持方差一致     |
| ReLU / LeakyReLU / GELU | He (Kaiming)        | 放大输入方差     |
| SELU                    | LeCun               | 保持自归一化性质 |
| Linear / Identity       | Xavier / Orthogonal | 信息保持性好     |

**总结对比表**

| **方法**                | **核心思想**     | **数学方差**   | **适用激活** | **优点**       | **缺点**       |
| ----------------------- | ---------------- | -------------- | ------------ | -------------- | -------------- |
| Random Uniform / Normal | 随机分布         | 自定义         | 通用         | 简单快速       | 容易梯度失衡   |
| Xavier                  | 输入输出方差一致 | 2/(n_in+n_out) | Sigmoid/Tanh | 收敛稳定       | 对 ReLU 不适用 |
| He (Kaiming)            | 考虑ReLU非对称性 | 2/n_in         | ReLU类       | 深层网络表现好 | 对非ReLU效果差 |
| LeCun                   | Self-Normalizing | 1/n_in         | SELU         | 稳定           | 仅限SELU       |
| Orthogonal              | 信息保持         | 固定           | 通用         | 防梯度爆炸     | 难于小网络     |
| LSUV                    | 动态调整方差     | 近1            | 通用         | 自动化好       | 预热慢         |
| Pretrained              | 数据驱动         | 无公式         | 通用         | 泛化强         | 需外部模型     |

参数初始化的核心目的是保持每层输入输出方差一致，避免梯度爆炸或消失。

常用方法有 Xavier（针对 Sigmoid/Tanh）、He 初始化（针对 ReLU）、LeCun（针对 SELU），

还有正交初始化和 LSUV 等改进方式。

不同激活函数和网络结构对应不同初始化策略，这是深层网络能稳定收敛的关键。
