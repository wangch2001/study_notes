# 介绍HSTU对Transformer的一个改进？

| 项目                     | 标准 Transformer 特点                                        | HSTU 的改进／不同                                            |
| ------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 注意力归一化机制         | 在 Self-Attention 里通常使用 softmax 对 (QK^\top) 做归一化 → 得到注意力权重，然后与 (V) 相乘。 | HSTU 采用 **point-wise 聚合注意力**（point-wise normalization）替换了 softmax-based 注意力。即不再强制 (QK^\top) 的输出概率化（sum to 1），而是改用每个 token 的单点变换方式。 |
| 关注的特征交互与序列特性 | Transformer 通常面向语言／自然序列，token vocab 固定、序列结构稳定。 | HSTU 面向推荐系统中 **高基数 (high-cardinality)、异构 (heterogeneous) 特征**、且行为序列不断变化（streaming, 非定长、时序依赖强）。因此其设计更多考虑特征交互 (feature interaction)、序列历史、时间差 (temporal) 等因素。 |
| 模块结构                 | 多头注意力 + 前馈 (FFN) 层 + 残差/层归一化。                 | HSTU 每层包含三子层：① Pointwise Projection，② Spatial Aggregation（注意力机制改造），③ Pointwise Transformation。 |
| 归一化 / 激活 &效率      | Softmax注意力 +多个线性层 → 在非常长序列或大 vocab 场景下，资源／激活内存占用、算力成为瓶颈。 | HSTU 降低了线性层数（例如部分实现中「将标准Transformer外部的线性层从 6 个减少到 2 个」），并针对注意力进行了高效实现（例如使用 grouped GEMMs、稀疏化、优化 GPU kernel）以加速训练／推理。 |
| 序列长度 &扩展           | Transformer 在极长序列 (例如用户行为史、推荐日志) 上可能受限于 (O(n^2)) 注意力、内存激活大小限制。 | HSTU 针对推荐系统历史序列长度、时序差 (timestamp) 做特别设计，如“relative positional attention + relative temporal attention”并支持更长序列。 |
| 应用场景                 | 多用于语言、视觉、标准序列建模。                             | HSTU 特别为 **推荐系统** (Recommender Systems) 设计，把用户行为序列看作 “语言” 构建 generative 模型。 |

## 三个子层详解

**:one: Pointwise Projection（逐点投影层）**

对输入特征向量进行线性映射（类似 Q/K/V 的生成），但不依赖于上下文。
 即 **每个 token 独立处理**，不发生 token 间交互。

#### 📐 公式：

$$U(X), V(X), Q(X), K(X) = \text{Split}(\phi_1(f_1(X)))$$

- X：输入向量（批量 × 序列长度 × 特征维度）
- $f_1$：线性变换（如全连接层）
- $\phi_1$：激活函数（如 SiLU）

🔍 类比：

相当于 Transformer 中：

> Linear projections → 产生 Q、K、V（但 HSTU 还多了一个 U）

💡 作用：

- 提取 token 层面的特征表示
- 为后续注意力交互提供输入
- 保留一个独立的 gating 信号（U）

**2️⃣ Spatial Aggregation（空间聚合层）**

这一层是 HSTU 的 **核心创新**。也包含归一化因子，只是没有进行softmax
 它类似 Transformer 的 **Self-Attention 层**，但：

- **不使用 Softmax**
- **不进行全局概率归一化**
- **加入相对位置 / 时间偏置**

📐 公式：

$$A(X)V(X) = \frac{\phi_2(Q(X)K(X)^T + rab^{p,t}) \cdot V(X)}{N}$$

- Q(X),K(X),V(X)：来自上一步的投影
- $rab^{p,t}$：relative attention bias（结合相对位置 + 时间信息）
- $\phi_2$：非线性函数（如 ReLU 或 SiLU），替代 Softmax
- N：归一化因子（非概率形式）

🔍 类比：

Transformer 的：

$$\text{softmax}\left(\frac{QK^T}{\sqrt{d}}\right) V$$

→ 被替换为更高效的 **点式非线性聚合 + 相对时间偏置**。

💡 优势：

- 避免了 Softmax 的全局归一化成本（内存友好）
- 计算复杂度更低，适合超长序列（推荐任务中序列可达上万步）
- 相对位置 + 时间信息提升时序建模能力

**3️⃣ Pointwise Transformation（逐点变换层）**

📘 功能：

将前一层的聚合结果（即上下文增强表示）进行非线性变换和门控融合。
 即：**对每个 token 独立地做输出变换**，形成层输出。

📐 公式：

$$Y(X) = f_2(\text{Norm}(A(X)V(X)) \odot U(X))$$

- A(X)V(X)：来自聚合层的上下文特征
- U(X)：来自第 1 层的门控信号
- ⊙：逐元素乘法（门控机制）
- $f_2$：线性层或前馈网络（相当于 FFN）
- $\text{Norm}$：归一化层（如 LayerNorm）

🔍 类比：

Transformer 的：

> Feed-Forward Network (FFN) + 残差 + LayerNorm

💡 作用：

- 对聚合结果进行再加工
- 利用 U(X) 实现自适应信息流控制（类似 gating）
- 输出最终更新后的 token 表示

| 阶段 | 子层                     | 功能描述                                       | 对应 Transformer     |
| ---- | ------------------------ | ---------------------------------------------- | -------------------- |
| 1️⃣    | Pointwise Projection     | 对输入逐点线性映射，生成 Q/K/V/U               | Linear(QKV)          |
| 2️⃣    | Spatial Aggregation      | 计算 QKᵀ + 相对偏置，再与 V 聚合（无 softmax） | Multi-Head Attention |
| 3️⃣    | Pointwise Transformation | 用门控信号融合聚合结果并非线性变换             | Feed-Forward Network |

## U矩阵有什么作用？为什么要多这一步操作

1️⃣ 控制信息流

因为HSTU去掉了残差网络连接，可以控制每个 token 的上下文聚合结果 A(X)V(X) 在输出中占多大权重。

模型可以让某些 token **更依赖上下文**（U 大），
 而另一些 token **保留自己的特征为主**（U 小）。

2️⃣ 避免冗余计算、增强表达灵活性

在标准 Transformer 中：

- Attention 输出 A V 和原输入 X 之间依靠 **残差连接 (residual)** 来混合；
- FFN 之后再通过 LayerNorm 调整分布。

而 HSTU 用U(X) 替代了这种「显式残差」：

> 用门控向量实现 **自适应的信息融合**，而不是固定的相加结构。

这种方式：

- 更轻量（参数更少）
- 更灵活（每个 token 的融合比例不同）
- 适合推荐系统中异构输入（比如有些特征重要、有些不重要）

3️⃣ 可视角度：U 是一种「自调制因子（Self-Modulation）」

在神经网络设计中，门控（gating）思想非常常见：

- 在 **LSTM** 中有输入门 / 遗忘门；
- 在 **GLU (Gated Linear Unit)** 中用 σ(Wx) ⊙ (Vx)；
- 在 **Swin Transformer / Gated Attention Unit (GAU)** 中也引入了 gate 向量调节流动。

HSTU 的 U 起的作用本质上与这些机制一致：
 它提供了一种 **对上下文信息流的逐 token 级调制**。

4️⃣ 残差消失风险小的任务特性

HSTU 主要面向 **推荐系统序列建模**（用户行为序列）。
 与语言模型的上千层深度不同，这类模型通常层数较少（10–40 层），
 序列长度虽长（几千步），但网络深度有限，因此梯度消失风险本身就更低。

换句话说，它的优化重点在于“计算效率”和“动态加权”，
 而不是极深网络的稳定训练。

:five:  门控机制 U(X) 提供了「可学习的直通路径」

HSTU 的核心输出形式为：

$$Y = f_2(\text{Norm}(A(X)V(X)) \odot U(X))$$

- U(X) 来自原输入 X，通过简单的线性层和激活函数生成；
- 在多数情况下，门控值 $U(X) \in (0, 1]$（例如经过 SiLU/ReLU 激活）；
- 当 $U(X) \approx 1$时，输出几乎就是 $\text{Norm}(A(X)V(X))$，
   相当于原始特征直接“透传”；
- 当 U(X) 变小时，信息被抑制，但梯度仍能通过 U(X) 传导。

🔹**关键点**：
 梯度可以沿着 U(X) 这个路径从上层反向流回输入。
 因此，U 扮演了类似 “残差旁路” 的角色，只不过是**乘法控制**而不是**加法融合**。

| 角度               | 原因                                                         |
| ------------------ | ------------------------------------------------------------ |
| 🧠 **信息流控制**   | 在 Transformer 里，所有 token 的聚合输出都一视同仁；HSTU 让每个 token 自己决定“要不要吸收那么多上下文”。 |
| ⚙️ **减少残差依赖** | 通过 U 的逐点门控，可以替代传统残差混合，提高效率。          |
| 🔍 **任务适配性**   | 在推荐系统中，不同特征（用户点击、时间戳、类别）重要性差异大，U 可以自动学习这些权重。 |
| 🚀 **计算效率**     | 线性门控比显式多分支残差结构更快、更节省显存。               |

## 为什么现在深度模型很少再显式地使用交叉模块？

早期的推荐系统特征都是**离散稀疏、高维手工特征**，单个 embedding 信息量很小，模型很难自动学出“feature interaction”。

所以显式交叉模块的作用是：

- 强行制造“特征之间的共现组合”；
- 通过手工公式或结构让模型捕捉二阶或高阶关系。

现代推荐模型

+ Embedding 表达能力增强，特征交互被隐式建模
+ 深层网络（MLP、Transformer、HSTU 等）本身已经具备强大的非线性组合能力
+ 显式交叉模块参数多、结构复杂，收益递减
+  新一代架构（Transformer / HSTU / DSSM / DIN / DIEN）天然具备交互建模能力

现代精排模型不再专门使用显式的“交叉模块”，
 是因为：

1. Embedding 和深层网络本身已经能隐式学习特征交互；
2. 显式交叉增加复杂度、容易过拟合、收益有限；
3. Transformer、HSTU、DIN 等结构天然具备全局交互建模能力。

因此，**交叉从“显式结构”变成了“隐式机制”。**

# 特征工程

1. **多模态语义特征（RQ-VAE）**
   + 由 `model_rqvae.py` 训练的 **Residual Quantized VAE (RQ-VAE)** 模型，对连续多模态 embedding（如图像特征、文本向量）进行**残差量化**，输出一组 **离散语义代码（semantic_id）**。
   + 将高维语义embedding → 紧凑离散token；
   + 跨模态特征统一（原本的多模态特征与推荐系统之间具有语义鸿沟）
   + 减少存储与计算量。
2. **时间特征工程（TimeEncoder）**
   + 结合离散 + 连续 + 周期编码三种方式，形成时间向量。
   + 提供精确的时间上下文，使模型能区分“短期兴趣”“长期兴趣”“时间周期性偏好”。
   + 周期性特征：使用正弦和余弦将其映射到二维空间：
     + $$x_{sin}=\sin(2\pi\cdot t/T)\\x_{cos}=\cos(2\pi\cdot t/T)$$
     + 当 t=0 与 t=T 接近时，sin/cos 值也接近
     + 时间变化在连续空间中平滑
     + 模型可通过线性层学习周期特征的相位关系。
3.  相对位置 & 相对时间偏置（HSTU内部自动生成）
   + 位置偏置（pos_buckets）
     + 输入：序列索引差 j−i；
     + 分桶后通过 Embedding(`num_pos_buckets`, `num_heads`);
     + 加入注意力打分矩阵。
   + 时间偏置（time_buckets）
     + 输入：行为间时间差 (t_j−t_i)；
     + 分桶后通过 Embedding(`num_time_buckets`, `num_heads`);
     + 作用于注意力层（HSTU）；
     + 学习时间衰减模式（如“近期行为更重要”）。
   + 模型能在序列依赖中自动学习**行为顺序 + 时间间隔对兴趣转移的影响**。
4. **行为特征**
   + 行为类型（点击/曝光/收藏）
   + 会话内顺序（session_pos）
   + 曝光权重（exposure_weight）
   + 时间衰减（recency_weight）(关注于近期所点击物品)
5. **特征交互与融合**
   + 物品特征 + 时间特征
   + 多模态特征 + ID特征
   + 序列上下文建模（HSTU）

## TimeEncoder时间编码器

**功能：**
 把时间相关的离散与连续特征（小时、星期、时段、Δt桶、会话位置、周期特征等）编码成一个定长时间embedding。
 最终输出形状为 `[B, L, time_dim]`。

**结构：**

- Embedding 特征：
  - 小时（hour_emb）
  - 星期几（dow_emb）
  - 一天的分段（part_emb）
  - 时间间隔桶化（dt_emb）
    + 前半线性、后半对数
    + 对于较小的时间间隔（例如前 8 个桶），每个桶对应固定时间长度
    + 对于较大的时间间隔，采用对数尺度，这样后面的桶会变得越来越宽
  - 会话内位置（spos_emb）
  - 周期特征 sin/cos 投影（cyc_proj）
    + `cyc_cont` 一般是通过周期函数构造的，如：$\sin(2\pi t/T),\cos(2\pi t/T)$ 
    + 对于两个周期（如小时、天）会生成 4 维向量：[sin_hour, cos_hour, sin_day, cos_day]
    + 线性层把这 4 维映射成 8 维：`c = self.cyc_proj(cyc_cont)  # (B, L, 8)`
  - 连续时间间隔 Δt 连续投影（dt_cont_proj）
    + 输入是连续时间间隔（如 log(1 + Δt) 秒）
    + 投影到 8 维`self.dt_cont_proj = nn.Linear(1, 8)`

**最终输出：**

$$\mathrm{time_emb}=\mathrm{Linear}([\mathrm{hour},\mathrm{dow},\mathrm{part},\mathrm{dt_bucket},\mathrm{spos},\mathrm{cyc,dt_cont}])$$

维度为 `time_dim`。

## RMSNorm / SwiGLU —— Transformer 基础组件

1️⃣ `RMSNorm`

轻量归一化层（Root Mean Square Normalization）：

```python
norm = x.pow(2).mean(dim=-1, keepdim=True).add(eps).rsqrt()
```

与 LayerNorm 相比更稳定、速度更快。

2️⃣ `SwiGLU`

前馈网络层（Feed-Forward Network）：

$$\mathrm{SwiGLU}(x)=(\mathrm{SiLU}(xW_g)\odot xW_u)W_d$$

是 PaLM / LLaMA 常用激活结构，比 ReLU 更平滑。

**SwiGLU** 是一种“**门控前馈层（Gated Feed-Forward Layer）**”，在普通 Transformer 的 FFN 结构上加入了 **乘性门控机制**。

**标准 FFN 的形式（Transformer）**

传统 Transformer 的前馈层（FFN）：

$$\mathrm{FFN}(x)=\mathrm{ReLU}(xW_1+b_1)W_2+b_2$$

或者 GeLU 版本：

$$\mathrm{FFN}(x)=\mathrm{GeLU}(xW_1)W_2$$

这里的激活函数是单输入的 —— 对每个 token 向量独立地做非线性变换。

 **SwiGLU 的改进思想**

SwiGLU 改成了**双输入结构**，使用门控机制：

$$\mathrm{SwiGLU}(x)=\mathrm{Swish}(xW_g)\odot(xW_u)W_d$$

其中：

- `W_g`：门控（gate）线性层；
- `W_u`：上升层（up）；
- `W_d`：降维层（down）；
- `Swish(x) = x * sigmoid(x)` 是光滑版的 ReLU；
- `⊙` 表示逐元素相乘。

👉 这样做的目的是：

> “用一个输入流控制另一个输入流的激活幅度”，
>  相当于在 FFN 中引入“动态注意力”。

## HSTULayer —— 轻量时空注意力模块

这是模型的「时空注意力块（Hybrid Spatio-Temporal Unit）」，类似 Transformer 的 Multi-Head Attention，但加入了：

- 相对位置偏置 `B_pos`（T5风格桶化）
- 相对时间偏置 `B_time`
- SiLU 点式聚合代替 Softmax
- 可选 ReLU 保证注意力非负
- Row-normalized（L1归一）

**相对位置和相对时间偏置**

这两个偏置共同让模型能在行为序列中**同时捕捉时序顺序关系**（position）与**真实时间间隔信息**（time），大幅增强了模型的时间敏感性与行为预测能力。

本模型引入：

$$\mathrm{score}_{ij}=\frac{Q_iK_j^T}{\sqrt{d_h}}+B_{ps}(i,j)+B_{time}(i,j)$$

其中：

- $B_{pos}(i,j)$：相对位置偏置；
- $B_{time}(i,j)$：相对时间偏置。

这两个偏置都是通过“桶化 + Embedding查表”的方式得到的。

+ **位置桶**来自**序列索引差**；
+ **时间桶**来自**时间戳差**；
+ 两者都是在 forward 阶段动态生成；
+ 然后喂给每一层 HSTU 以添加偏置。

其中相对位置分桶和相对时间分桶都有一个独立的可学习偏置向量，遵循「线性 + 对数」策略

## InfoNCE 对比损失：compute_infonce_loss()

**计算逻辑：**

1. 取出有效位置；
2. 归一化向量；
3. 正样本相似度：`cos(seq, pos)`；
4. 负样本池：所有 batch 内的 `neg_embs`；
5. 拼接 `[pos, neg1, neg2, ...]`；
6. CrossEntropy 形式的 InfoNCE 损失。

$$L_{InfoNCE}=-\frac{1}{N}\sum_{i}\log\frac{e^{s_{i,pas}/\tau}}{e^{s_{i,pos}/\tau}+\sum_{j\neq i}e^{s_{i,nag_{j}}/\tau}}$$

此损失迫使正样本 embedding 更接近用户历史 embedding，负样本远离。

## 损失函数

| 损失                         | 公式                                                         | 作用                     |
| ---------------------------- | ------------------------------------------------------------ | ------------------------ |
| **BCE (点击预测)**           | $-[y\log σ(s) + (1-y)\log (1-σ(s))]$                         | 预测点击概率（基础任务） |
| **Triplet (embedding 结构)** | $\max(0, d(a,p)-d(a,n)+m)$                                   | 拉近正样本、推远负样本   |
| **InfoNCE (对比学习)**       | $-\log \frac{e^{s_{pos}/τ}}{e^{s_{pos}/τ} + \sum e^{s_{neg}/τ}}$ | 全局特征对齐             |

完整损失：

$$L=w_{BCE}\cdotp L_{BCE}+w_{Triplet}\cdot L_{Triplet}+w_{InfoNCE}\cdotp L_{InfoNCE}$$

| 损失    | 类比     | 类似任务               | 你模型中的作用                     |
| ------- | -------- | ---------------------- | ---------------------------------- |
| BCE     | 二分类器 | CTR预测、Next-item预测 | “点级监督”：学会点击概率           |
| Triplet | 度量学习 | FaceNet、人脸识别      | “局部监督”：学会embedding几何距离  |
| InfoNCE | 对比学习 | SimCLR、CLIP           | “全局监督”：学会语义对齐与时间感知 |

训练过程中：

1. BCE 保证模型能预测正确（排序方向正确）；
2. Triplet 保证 embedding 空间的**局部几何稳定性**；
3. InfoNCE 保证 embedding 的**全局可分性与泛化能力**。

BCE 提供“任务导向”，Triplet 保证“空间合理”，InfoNCE 保证“语义清晰”。
