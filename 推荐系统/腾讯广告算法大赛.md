# 特征工程

1. **多模态语义特征（RQ-VAE）**
   + 由 `model_rqvae.py` 训练的 **Residual Quantized VAE (RQ-VAE)** 模型，对连续多模态 embedding（如图像特征、文本向量）进行**残差量化**，输出一组 **离散语义代码（semantic_id）**。
   + 将高维语义embedding → 紧凑离散token；
   + 跨模态特征统一（原本的多模态特征与推荐系统之间具有语义鸿沟）
   + 减少存储与计算量。
2. **时间特征工程（TimeEncoder）**
   + 结合离散 + 连续 + 周期编码三种方式，形成时间向量。
   + 提供精确的时间上下文，使模型能区分“短期兴趣”“长期兴趣”“时间周期性偏好”。
   + 周期性特征：使用正弦和余弦将其映射到二维空间：
     + $$x_{sin}=\sin(2\pi\cdot t/T)\\x_{cos}=\cos(2\pi\cdot t/T)$$
     + 当 t=0 与 t=T 接近时，sin/cos 值也接近
     + 时间变化在连续空间中平滑
     + 模型可通过线性层学习周期特征的相位关系。
3.  相对位置 & 相对时间偏置（HSTU内部自动生成）
   + 位置偏置（pos_buckets）
     + 输入：序列索引差 j−i；
     + 分桶后通过 Embedding(`num_pos_buckets`, `num_heads`);
     + 加入注意力打分矩阵。
   + 时间偏置（time_buckets）
     + 输入：行为间时间差 (t_j−t_i)；
     + 分桶后通过 Embedding(`num_time_buckets`, `num_heads`);
     + 作用于注意力层（HSTU）；
     + 学习时间衰减模式（如“近期行为更重要”）。
   + 模型能在序列依赖中自动学习**行为顺序 + 时间间隔对兴趣转移的影响**。
4. **行为特征**
   + 行为类型（点击/曝光/收藏）
   + 会话内顺序（session_pos）
   + 曝光权重（exposure_weight）
   + 时间衰减（recency_weight）(关注于近期所点击物品)
5. **特征交互与融合**
   + 物品特征 + 时间特征
   + 多模态特征 + ID特征
   + 序列上下文建模（HSTU）



# model.py

## TimeEncoder时间编码器

**功能：**
 把时间相关的离散与连续特征（小时、星期、时段、Δt桶、会话位置、周期特征等）编码成一个定长时间embedding。
 最终输出形状为 `[B, L, time_dim]`。

**结构：**

- Embedding 特征：
  - 小时（hour_emb）
  - 星期几（dow_emb）
  - 一天的分段（part_emb）
  - 时间间隔桶化（dt_emb）
    + 前半线性、后半对数
    + 对于较小的时间间隔（例如前 8 个桶），每个桶对应固定时间长度
    + 对于较大的时间间隔，采用对数尺度，这样后面的桶会变得越来越宽
  - 会话内位置（spos_emb）
  - 周期特征 sin/cos 投影（cyc_proj）
    + `cyc_cont` 一般是通过周期函数构造的，如：$\sin(2\pi t/T),\cos(2\pi t/T)$ 
    + 对于两个周期（如小时、天）会生成 4 维向量：[sin_hour, cos_hour, sin_day, cos_day]
    + 线性层把这 4 维映射成 8 维：`c = self.cyc_proj(cyc_cont)  # (B, L, 8)`
  - 连续时间间隔 Δt 连续投影（dt_cont_proj）
    + 输入是连续时间间隔（如 log(1 + Δt) 秒）
    + 投影到 8 维`self.dt_cont_proj = nn.Linear(1, 8)`

**最终输出：**

$$\mathrm{time_emb}=\mathrm{Linear}([\mathrm{hour},\mathrm{dow},\mathrm{part},\mathrm{dt_bucket},\mathrm{spos},\mathrm{cyc,dt_cont}])$$

维度为 `time_dim`。

## RMSNorm / SwiGLU —— Transformer 基础组件

1️⃣ `RMSNorm`

轻量归一化层（Root Mean Square Normalization）：

```python
norm = x.pow(2).mean(dim=-1, keepdim=True).add(eps).rsqrt()
```

与 LayerNorm 相比更稳定、速度更快。

2️⃣ `SwiGLU`

前馈网络层（Feed-Forward Network）：

$$\mathrm{SwiGLU}(x)=(\mathrm{SiLU}(xW_g)\odot xW_u)W_d$$

是 PaLM / LLaMA 常用激活结构，比 ReLU 更平滑。

**SwiGLU** 是一种“**门控前馈层（Gated Feed-Forward Layer）**”，在普通 Transformer 的 FFN 结构上加入了 **乘性门控机制**。

**标准 FFN 的形式（Transformer）**

传统 Transformer 的前馈层（FFN）：

$$\mathrm{FFN}(x)=\mathrm{ReLU}(xW_1+b_1)W_2+b_2$$

或者 GeLU 版本：

$$\mathrm{FFN}(x)=\mathrm{GeLU}(xW_1)W_2$$

这里的激活函数是单输入的 —— 对每个 token 向量独立地做非线性变换。

 **SwiGLU 的改进思想**

SwiGLU 改成了**双输入结构**，使用门控机制：

$$\mathrm{SwiGLU}(x)=\mathrm{Swish}(xW_g)\odot(xW_u)W_d$$

其中：

- `W_g`：门控（gate）线性层；
- `W_u`：上升层（up）；
- `W_d`：降维层（down）；
- `Swish(x) = x * sigmoid(x)` 是光滑版的 ReLU；
- `⊙` 表示逐元素相乘。

👉 这样做的目的是：

> “用一个输入流控制另一个输入流的激活幅度”，
>  相当于在 FFN 中引入“动态注意力”。

## HSTULayer —— 轻量时空注意力模块

这是模型的「时空注意力块（Hybrid Spatio-Temporal Unit）」，类似 Transformer 的 Multi-Head Attention，但加入了：

- 相对位置偏置 `B_pos`（T5风格桶化）
- 相对时间偏置 `B_time`
- SiLU 点式聚合代替 Softmax
- 可选 ReLU 保证注意力非负
- Row-normalized（L1归一）

**相对位置和相对时间偏置**

这两个偏置共同让模型能在行为序列中**同时捕捉时序顺序关系**（position）与**真实时间间隔信息**（time），大幅增强了模型的时间敏感性与行为预测能力。

本模型引入：

$$\mathrm{score}_{ij}=\frac{Q_iK_j^T}{\sqrt{d_h}}+B_{ps}(i,j)+B_{time}(i,j)$$

其中：

- $B_{pos}(i,j)$：相对位置偏置；
- $B_{time}(i,j)$：相对时间偏置。

这两个偏置都是通过“桶化 + Embedding查表”的方式得到的。

+ **位置桶**来自**序列索引差**；
+ **时间桶**来自**时间戳差**；
+ 两者都是在 forward 阶段动态生成；
+ 然后喂给每一层 HSTU 以添加偏置。

其中相对位置分桶和相对时间分桶都有一个独立的可学习偏置向量，遵循「线性 + 对数」策略

## InfoNCE 对比损失：compute_infonce_loss()

**计算逻辑：**

1. 取出有效位置；
2. 归一化向量；
3. 正样本相似度：`cos(seq, pos)`；
4. 负样本池：所有 batch 内的 `neg_embs`；
5. 拼接 `[pos, neg1, neg2, ...]`；
6. CrossEntropy 形式的 InfoNCE 损失。

$$L_{InfoNCE}=-\frac{1}{N}\sum_{i}\log\frac{e^{s_{i,pas}/\tau}}{e^{s_{i,pos}/\tau}+\sum_{j\neq i}e^{s_{i,nag_{j}}/\tau}}$$

此损失迫使正样本 embedding 更接近用户历史 embedding，负样本远离。

## 损失函数

| 损失                         | 公式                                                         | 作用                     |
| ---------------------------- | ------------------------------------------------------------ | ------------------------ |
| **BCE (点击预测)**           | $-[y\log σ(s) + (1-y)\log (1-σ(s))]$                         | 预测点击概率（基础任务） |
| **Triplet (embedding 结构)** | $\max(0, d(a,p)-d(a,n)+m)$                                   | 拉近正样本、推远负样本   |
| **InfoNCE (对比学习)**       | $-\log \frac{e^{s_{pos}/τ}}{e^{s_{pos}/τ} + \sum e^{s_{neg}/τ}}$ | 全局特征对齐             |

完整损失：

$$L=w_{BCE}\cdotp L_{BCE}+w_{Triplet}\cdot L_{Triplet}+w_{InfoNCE}\cdotp L_{InfoNCE}$$

| 损失    | 类比     | 类似任务               | 你模型中的作用                     |
| ------- | -------- | ---------------------- | ---------------------------------- |
| BCE     | 二分类器 | CTR预测、Next-item预测 | “点级监督”：学会点击概率           |
| Triplet | 度量学习 | FaceNet、人脸识别      | “局部监督”：学会embedding几何距离  |
| InfoNCE | 对比学习 | SimCLR、CLIP           | “全局监督”：学会语义对齐与时间感知 |

训练过程中：

1. BCE 保证模型能预测正确（排序方向正确）；
2. Triplet 保证 embedding 空间的**局部几何稳定性**；
3. InfoNCE 保证 embedding 的**全局可分性与泛化能力**。

BCE 提供“任务导向”，Triplet 保证“空间合理”，InfoNCE 保证“语义清晰”。
