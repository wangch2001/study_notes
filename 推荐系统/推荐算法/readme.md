后面是我的笔记

1.题目理解
数据来自某新闻APP，有30万用户、近300万次点击和36万多篇新闻文章，每篇文章还有对应的embedding向量。为了比赛公平，划分了训练集、测试集A和测试集B
2.数据规模
统计发现训练集有20万用户、31,116篇文章、1,112,623次点击；测试集有5万用户、16,330篇文章、518,010次点击。总共出现的item约36000篇文章。
3.数据处理
训练集中随机挑出五万个用户，将他们的最后一次点击取出来做验证集。抽出用户的其余点击和未抽出用户的所有点击加入训练集，测试集的所有数据加入训练集。
验证集有两列 ，每个用户的id和点击文章的id，抽出的用户第二列是实际id，测试机用户的文章id是-1，一部分用于模型训练，一部分用于最终结果生成。
4.baseline
baseline是itemcf，建立用户点击字典，根据同一个user点击的不同item计算贡献矩阵，物品相似矩阵的构建时，每对物品的权重只做了用户历史序列长度惩罚项
5.itemcf召回
在baseline的基础上增加了基于点击次序的影响。同一点击序列中两个新闻位置越远，相关性越小，同时正序和逆序的权重也不一样(1.0/0.7)，实际上的sim权重取决于两个新闻的点击顺序，位置差，用户点击总数和两文章的点击量。
召回时，对于验证集的每个用户，取出每个用户的最后两次点击，通过查询相似矩阵计算出最相似的物品，取前100个item，去除训练集中已点击过的item，按照sim_score进行降序排序，得到每个用户的召回序列。根据每个用户的召回结果是否在验证集和用户的种类，为label置不同的值，用来计算hitrate5(0.33)和mrr5(0.20)
6.binetwork召回(基于网络关系)
相比于itemcf，共现矩阵的计算方式发生了变化,同一个user点击的不同item对权重的贡献受用户点击序列和物品被点击次数的长度影响。0.34, 0.20 但是在最终召回合并环节中和itemcf的相似度只有0.28
7.w2w召回
把每个用户点击的文章列表当作一句话，每篇文章作为一个词，所有用户的点击序列组成了“一个语料库”，直接输入gensim的w2v库。表示上下文窗口大小为3,使用skip-gram模型（更适合小数据，更能学到稀疏关系），使用负采样，采样的个数为5。
召回时，用 Word2Vec学到的文章向量，通过Annoy(近似最近邻，优先队列和森林)召回与用户最近看过文章相似度最高的50篇文章。0.12, 0.06
8.召回合并
为协同过滤、词向量、二部图网络设定不同的权重，对不同召回的相似分数做归一化处理。按照权重计算新的相似度分数，经过去重、合并后排序相似度分数。去重之后，平均每个用户召回到153个新闻。合并后的hr和mrr分别为0.37, 0.22
9.特征工程
加载recall阶段合并好的召回序列，用户的点击序列和文章的特征信息。
特征工程分为3类：新闻特征，用户特征，用户-新闻交互特征。

新闻特征包括：字数、创建时间、阅读量

用户特征包括：
用户点击新闻的创建时间差的平均值
用户点击新闻的点击时间差的平均值
用户点击新闻的点击-创建时间差的统计值：mean，std
用户点击新闻的 click_datetime_hour 统计值
用户点击新闻的字数统计值
用户点击新闻的创建时间统计值
用户点击新闻的点击时间统计值
用户新闻阅读数量
用户某种类新闻阅读数量

交互特征：
待预测新闻和用户所有历史点击新闻相似度按次序加权求和
待预测新闻和用户最近一次点击新闻相似度
直接做拼接形成最后的训练集，输入lgb模型。
🔝 高重要性特征
特征名	含义解释
sim_score	推荐候选文章与用户历史点击文章的综合相似度分数，可能融合了多种相似度指标（如w2v、itemcf等）。
user_last_click_timestamp_diff	当前文章与用户最后一次点击文章之间的时间差，衡量用户对当前内容的“时效性”偏好。
user_last_click_article_itemcf_sim	当前文章与用户最近一次点击文章之间的ItemCF相似度。
user_last_click_article_w2v_sim	当前文章与用户最后点击文章之间的词向量相似度（可能是标题或内容的embedding）。
user_clicked_article_itemcf_sim_sum	当前文章与用户点击过的所有文章的ItemCF相似度总和，反映整体兴趣匹配程度。
article_id_cnt	当前文章在整个数据集中被点击的次数，类似于热度指标。
user_last_click_created_at_ts_diff	当前文章与用户上次点击文章在创建时间上的差异（非点击时间）。
user_last_click_article_binetwork_sim	用户最近点击文章与当前文章在双向图网络中相似度（如图嵌入方法生成）。

10.lgb排序
本方案把排序建模为二分类任务，采用LGB模型
将训练集中带有标签的数据用于训练，无标签的数据用于预测，直接输入lgb模型。
num_leaves=64	叶子节点数64
max_depth=10	树的最大深度10
learning_rate=0.05	学习率
subsample=0.8	构建每棵树时随机采样80%的数据，提升泛化能力
feature_fraction=0.8	构建每棵树时随机选择80%的特征，提升泛化能力
reg_alpha=0.5	L1 正则化，控制模型稀疏性
reg_lambda=0.5	L2 正则化，控制模型权重大小
importance_type='gain'	信息增益”计算特征贡献
损失函数：默认的二元交叉熵损失，评估指标：auc
五折交叉训练，缓解数据分布偶然性，提升结果稳定性，提高模型的泛化能力确保每一个用户的数据都会学习到
